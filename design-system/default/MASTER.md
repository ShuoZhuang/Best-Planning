# 智能日程设计系统

> 视觉基准：`design/visual-directions/direction-3-focus-console-selected.png`

**Design Dials:** Variance 6/10 | Motion 4/10 | Density 7/10

## 1. 设计意图

这是面向大学生的桌面时间控制台。界面需要同时表达“现在做什么”“今天怎样展开”“未来七天是否拥堵”“调整为什么发生”，但不能制造监控感和焦虑。视觉以精确、克制、可信为主，生活与休息和学业任务同等可见。

## 3. 字体与数字

- 中文 UI 使用系统无衬线回退：`Microsoft YaHei UI`、`Microsoft YaHei`、`sans-serif`。
- 标题 30/36、24/30、18/24；正文 14/22；辅助文字 12/18。
- 标题使用 600–700 字重，正文使用 400–500。
- 时间、时长、百分比使用等宽数字特性；不要把所有标题设为等宽字体。
- 页面只允许一个一级标题；主行动文案保持简短。

## 4. 空间与形状

- 基础间距：4、8、12、16、20、24、32。
- 桌面导航宽度约 184–208；主内容区最小边距 20。
- 小控件半径 8，面板半径 12，状态标签使用全圆角。
- 面板默认只有 1px 轮廓，不使用外阴影；弹层可使用一层深色阴影。
- 用分隔线、背景层级和留白分组；禁止卡片套卡片和每行一个浮动卡片。

## 5. 组件语言

- 导航：图标和文字同时出现，选中项用钴蓝低透明底、左侧强调线和高亮文字共同表达。
- 主按钮：实心钴蓝、暖白文字、44px 最小高度；悬停提高亮度，按下缩小至 0.98。
- 次按钮：透明或一级表面，1px 轮廓；不要与主按钮争夺注意力。
- 时间轴：左侧时间刻度 + 当前时间线 + 连续日程块；固定、保护、可移动、生活事项必须同时使用图标/文字和色彩。
- 面板：标题、操作和内容保持同一对齐线；指标优先用数字和微型可视化，不用三张等宽 KPI 卡。
- 表单：标签永远在输入框外；错误信息靠近字段；键盘焦点使用 2px 钴蓝外框。

## 6. 动效与状态

- 页面切换与面板展开：180–240ms，`easeOutCubic`。
- 拖拽和重排必须表现空间连续性；不得使用装饰性循环动画。
- 支持减少动态效果；此时取消位移和缩放，只保留即时或淡入状态变化。
- 所有核心控件提供 hover、focus、pressed、disabled、loading、empty 和 error 状态。

## 7. 可访问性

- 正文对比度至少 4.5:1，大字号和图形至少 3:1。
- 鼠标点击目标和键盘操作目标最小 44×44。
- 所有图标按钮提供语义标签和 tooltip。
- 状态不依赖颜色 alone；图标、文字或形状必须提供第二信息通道。
- Tab 顺序跟随视觉顺序；不要移除默认焦点而不给替代样式。

## 8. 禁止模式

- 默认 Material `ColorScheme.fromSeed` 直接出厂。
- 浅蓝卡片铺满页面、重阴影、随机渐变或玻璃效果。
- 每个标题都配装饰图标或标签。
- 为“高级感”使用极小字号、低对比灰字和过长动画。
- 为了还原方向稿而伪造用户数据；空数据必须显示真实空状态。
