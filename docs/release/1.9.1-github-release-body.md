# 优计主义 1.9.1 更新

1.9.1 是新自动更新链路的首个正式目标版本。已经安装 1.9.0 的用户不必再手动寻找安装包；软件会在后台下载并验证这一版，等你点击左下角的更新入口后再安装。

## 首次完整使用自动更新

- `1.9.0` 会从固定地址读取 `1.9.1` 的签名清单，并比较 MSIX 版本
- 安装包在后台下载，支持断点续传和网络恢复，不会弹出催促窗口
- 下载完成后左下角显示更新入口；你不点击时，软件不会自行退出或安装
- 点击入口后不会再出现第二个确认框，但存在未保存编辑时会明确阻止安装

## 安装前再次验证

- 主程序和独立更新助手都会核对安装包大小、SHA-256、数字签名、发布者、包身份、架构和版本
- 更新助手只接受更新目录中已经完成下载的 `.ready` 文件，不执行脚本，也不接受其他路径里的程序
- 安装开始前会再次读取当前包版本并取得跨进程锁，重复点击不会启动多个更新事务

## 启动确认与回退基线

- 安装完成后由更新助手通过应用的固定 AUMID 启动 1.9.1
- 新版本通过数据库、包身份和更新状态健康检查后，`1.9.1` 会成为新的回退基线
- 健康确认完成前会保留 1.9.0 安装包和更新前数据快照
- 如果新版无法启动或健康检查超时，在回退条件满足时会恢复 1.9.0 和更新前数据
- 回退过的目标版本会暂停自动安装，只有手动重试后才会再次尝试

## 错误提示更清楚

- 网络暂时不可用、空间不足、签名失败、身份不符和安装服务忙会显示不同原因
- 可以重试的故障会保留已经验证的下载片段；确定性的签名或身份错误不会反复下载
- 更新状态页可以查看当前阶段、目标版本和简明错误信息，也可以清理诊断日志

## 数据与兼容性

- 应用版本为 `1.9.1+47`，MSIX 版本为 `1.9.1.0`
- 包身份和数据库结构与 `1.9.0` 相同，不需要数据迁移
- 任务、计划、课程、设置、偏好和历史记录都会保留
- `1.8.1` 及更早版本没有新更新组件；可以手动安装 `1.9.0` 后自动升级，也可以直接手动安装 `1.9.1`

## 已知限制

- 自动安装只适用于已经安装 `1.9.0` MSIX 的 Windows x64 用户
- 便携版、`1.8.1` 及更早版本需要手动下载并安装
- 更新入口不会绕过未保存编辑，也不会在用户未点击时自动安装
- Microsoft Store、差分补丁和其他桌面系统不在本次范围内

1.9.0 用户：等待左下角出现更新入口，点击即可。手动安装时，请完全退出应用和托盘图标后再双击 `BestPlanning_1.9.1.0_x64.msix`。
