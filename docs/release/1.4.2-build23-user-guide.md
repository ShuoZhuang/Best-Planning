# 智能日程 1.4.2+23（开发构建／待验收）

本版是**视觉纠偏**版：日程卡片的深浅、描边与跨页面一致性被修正，没有新增功能，也没有改动数据
结构。同时提供 MSIX 安装包和便携版；日常体验建议安装 MSIX，便携版用于安装失败时排查或临时运行。

## 安装或升级

1. 如果“智能日程”正在运行，请先退出程序；必要时在任务栏托盘图标菜单中选择退出。
2. 双击 `PersonalPlanner-1.4.2-build23-windows-x64-20261006.msix`。
3. 选择“安装”或“更新”。本版 MSIX 版本为 `1.4.2.1`，可以**原位覆盖**本机已有的 `1.4.2.0`
   或 `1.4.1.0`（不需要先卸载，现有任务、领域颜色、课表和设置都会保留）。
4. 安装完成后，从开始菜单启动“智能日程”。

如果 Windows 提示证书不受信任，请先安装同目录的 `PersonalPlanner-signing-cert.cer`：

1. 双击证书，选择“安装证书”。
2. 选择“当前用户”。
3. 选择“将所有的证书都放入下列存储”，将证书放入“受信任人”。
4. 完成证书导入后，再双击 MSIX 安装包。

证书主题应为 `CN=Shuo Zhuang, O=Personal User, C=CN`，指纹应为
`9E157ECE535D16A224593CA39C084705A4FD3C13`。只有核对一致后才应信任。

> **版本只能往上走**：Windows 不接受比已安装版本更低的安装包。一旦装过 `1.4.2.1`，就回不到
> `1.4.2.0` 及更早的号。

## 便携版

保留本目录内全部运行文件，然后双击 `personal_planner.exe`。不要只把 EXE 单独复制出去；它依赖同目录
的 DLL 和 `data` 文件夹。便携版会在运行目录建立自己的 `user-data`，与安装版的使用场景分开。

## 本次变化

- **卡片变深、并且回到旧版的重量**：今日、七日日历、单日详情的日程卡片改用**不透明**深色填充
  （由分类色按 `18%` 混入深色表面派生）与低亮描边，不再“发白、发灰、描边发光”，主按钮重新成为
  页面上最醒目的元素。
- **三个页面颜色一致**：同一条事项在今日、七日日历、单日详情里逐值同色，不再出现
  “今日比七日日历浅一半”的割裂。
- **四种玻璃材质不再影响卡片**：无玻璃／克制／激进／极致切换时，页面背景会变，卡片表面不漂移。
- **分类方式不变**：仍是“领域 + 保护时间 + 无领域任务／无领域固定日程”。同一领域下的固定日程
  与可移动任务同色，类型只由图标区分；领域原色保留在左侧色条、时间轴圆点、图标与图例等小面积上。

> 与上一版候选（`1.4.2+22` / MSIX `1.4.2.0`）的差别只有一处：卡片填充的混合比例由 `26%` 降到
> `18%`。上一版虽然已经不透明、不漂移，但对色板里较浅的几个颜色仍显得偏淡。
