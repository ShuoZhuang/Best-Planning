# 优计主义 1.9.2 更新

1.9.2 是一个**很小的前置修复版**：只修更新助手的回退能力，没有界面或业务变化。
建议在升级 1.10.0 之前先更新到 1.9.2。

## 修了什么

- 自动更新失败、需要回退时，助手此前会因“不允许降级部署”而回退失败，用户停在新版本。
  现在回退使用 Windows 的强制降级部署，并会先关闭仍占用安装包的新版本进程。
- 回退失败时把真实的 Windows 错误码写进 `helper-status.json`，便于定位是“降级被拒”
  还是“安装包被占用”。
- 普通升级路径仍然**不允许降级**，这条安全约束没有放松。

## 为什么需要它

自动回退由“当前已安装版本”内置的更新助手执行。已经发布的 1.9.0 / 1.9.1 内置的是旧助手，
从它们直接升到 1.10.0 时如果健康确认失败，无法自动回退。先升到 1.9.2，助手就是修复后的版本，
之后的升级才有自动回退能力。

已验证：`1.9.2 → 1.10.0` 健康确认超时后回退成功（退出码 7，回到 `1.9.2.0` 并重新启动旧版）。
验证记录见 `docs/testing/v1.10.0-update-rollback-acceptance.md`。

## 升级方式

- 已经安装 1.9.0 / 1.9.1：等应用内提示，或在“设置 → 检查更新”里更新到 1.9.2；
- 也可以直接运行 `BestPlanning_Setup_1.9.2_x64.exe`（不会删除任务与设置）；
- 从 1.9.0/1.9.1 升到 1.9.2 的这一跳仍然没有自动回退（旧助手的限制），但 1.9.2 本身
  没有业务变更，风险很低；如遇异常，按“已知限制”手动恢复。

## 已知限制

- 从 1.9.0 / 1.9.1 升到 1.9.2 的那一跳不会自动回退；1.9.2 起，后续升级可正常回退。
- 同版本的“修复安装”只重新登记应用，不会替换已安装文件；文件损坏需要先卸载再安装。
