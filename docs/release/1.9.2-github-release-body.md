# 优计主义 1.9.2 更新（发布后更正）

> **更正说明（2026-10-18）**：发布后验证发现，`1.9.x` 的应用内更新存在缺陷——更新助手从
> 安装包内部启动，自己占住包文件，Windows 会以“包正在使用”（`0x80073D02`）拒绝安装。
> 因此 **`1.9.2` 无法通过应用内更新送达，也无法从 `1.9.2` 应用内升级到 `1.10.0`**。
> 请直接手动安装 `1.10.0`（`BestPlanning_Setup_1.10.0_x64.exe`），该版本已修复此问题，
> 之后的版本可以正常应用内更新。
>
> 本版本不再作为升级路径的一部分；保留它只是为了不重新绑定已发布的版本号。

## 1.9.2 原本修复什么

- 新版本启动后如果健康确认失败，更新助手会回退到上一版；此前的回退会因为 Windows
  不允许降级部署而失败，用户停在新版本
- 现在回退使用强制降级部署，并先关闭仍占用安装包的新版本进程
- 回退失败时会把真实的 Windows 错误码写进 `helper-status.json`，便于定位是“降级被拒”
  还是“安装包被占用”
- 普通升级路径仍然**不允许降级**，这条安全约束没有放松

## 为什么现在不推荐安装 1.9.2

- `1.9.x` 的应用内更新本身不可用，装 1.9.2 不能让你获得自动升级能力
- 从 `1.9.2` 应用内升级到 `1.10.0` 仍会被 `0x80073D02` 拒绝
- 直接手动安装 `1.10.0` 一次，才能获得新的安装器与可用的应用内更新

## 数据与兼容性

- 应用版本为 `1.9.2+48`，MSIX 版本为 `1.9.2.0`
- 包身份和数据库结构与 `1.9.1` 相同，不需要数据迁移
- 任务、计划、课程、设置、偏好和历史记录都会保留

## 已知限制

- `1.9.x` 无法应用内升级到任何新版本（含 `1.9.2` 与 `1.10.0`），需要手动安装
- 同版本的“修复安装”只重新登记应用，不会替换已安装文件；文件损坏需要先卸载再安装

安装：请改为下载 `1.10.0` 的 `BestPlanning_Setup_1.10.0_x64.exe` 手动安装一次。
