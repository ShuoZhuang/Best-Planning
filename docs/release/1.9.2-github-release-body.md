# 优计主义 1.9.2 更新

1.9.2 是一个很小的前置修复版，只修自动更新的回退能力，没有界面或业务变化。建议在升级
1.10.0 之前先更新到 1.9.2。

## 回退失败已修复

- 新版本启动后如果健康确认失败，更新助手会回退到上一版；此前的回退会因为 Windows
  不允许降级部署而失败，用户停在新版本
- 现在回退使用强制降级部署，并先关闭仍占用安装包的新版本进程
- 回退失败时会把真实的 Windows 错误码写进 `helper-status.json`，便于定位是“降级被拒”
  还是“安装包被占用”
- 普通升级路径仍然**不允许降级**，这条安全约束没有放松

## 为什么建议先升级到 1.9.2

- 自动回退由**当前已安装版本**内置的更新助手执行
- 已经发布的 1.9.0 / 1.9.1 内置的是旧助手；从它们直接升到 1.10.0 时，如果健康确认失败，
  无法自动回退
- 先升级到 1.9.2 后，助手就是修复后的版本；之后再升级 1.10.0 就有自动回退能力
- 已实测：`1.9.2 → 1.10.0` 健康确认超时后回退成功（退出码 7，回到 `1.9.2.0` 并重新启动旧版）

## 数据与兼容性

- 应用版本为 `1.9.2+48`，MSIX 版本为 `1.9.2.0`
- 包身份和数据库结构与 `1.9.1` 相同，不需要数据迁移
- 任务、计划、课程、设置、偏好和历史记录都会保留
- `1.9.0` / `1.9.1` 可以直接覆盖安装；建议先保存一份数据备份

## 已知限制

- 从 `1.9.0` / `1.9.1` 升到 `1.9.2` 的这一跳仍然没有自动回退（旧助手的限制）；1.9.2 起，
  后续升级可正常回退
- 同版本的“修复安装”只重新登记应用，不会替换已安装文件；文件损坏需要先卸载再安装
- 自动更新只适用于已安装 MSIX 的 Windows x64 用户，便携版仍需手动下载

安装：下载完整 ZIP，解压后**双击「安装.cmd」**即可。
