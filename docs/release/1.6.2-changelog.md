# 智能日程 `1.6.2` 更新点清单

**版本** `1.6.2+37` · **MSIX** `1.6.2.0` · Windows 10/11 x64
**发布时间** 2026-10-08 · **tag** `v1.6.2-build37`

> 这是 `1.6.2` 实际对外发布的更新点清单（42 条，逐条分列）。
> 发布正文见 `1.6.2-github-release-body.md`；完整叙述版说明见 `1.6.2-release-notes.md`。

任务怎么排、今天是哪几件事、时间花在哪、设置在哪改——这四件事此前各自能用但接不起来，
这一版把它们接成闭环。

## 新增

1. **任务清单四类筛选**：「全部 / 待安排 / 已安排 / 已完成」，每类带数量，可用键盘切换，窄窗可横向滚动
2. **任务卡片显示真实状态**：`待安排 · 预计 50 分钟`、`已安排 · 13:00–14:30`、`已完成 · 实际投入 25 分钟`
3. **逾期提示**：卡片上加「已逾期 · 截止于…」
4. **「跳过本次」动作**：只丢掉今天这一块，任务仍是待办，剩余时间不变（只扣真实专注过的部分），系统重新找空档
5. **「延后到明天」与「取消任务」**：与「跳过本次」完全分开的三个动作
6. **计划预览的分类展示**：把变更分成 新增 / 移动 / 拆分 / 未安排 / 保护时间变化，并列出原时间与目标时间
7. **周视图「时间轴」模式**：按真实时间比例绘制，一小时就是一小时那么高
8. **重叠事项并排显示**：不会一个盖住另一个
9. **时间轴上显示真实起止时间**，长标题省略、可悬停看全
10. **周视图「紧凑 / 时间轴」切换**，默认紧凑，选择会被记住
11. **课表导入失败时就地给「更换图片」**
12. **课表导入失败时说清是哪张图**（只给文件名，不含目录路径）**与支持的格式**（PNG/JPG/JPEG）
13. **设置首页四组分区**：规划与时间 / 外观与交互 / 通知与隐私 / 数据与帮助
14. **设置入口显示当前值**：例如"默认专注 50 分钟"、"材质：克制"
15. **首次引导的三个操作入口**：创建第一个任务 / 导入课表 / 了解主要界面
16. **引导中途退出的续接询问**：「上次的新手引导还没有完成」+［继续引导］［重新开始］［暂时跳过］
17. **设置里新增「首次引导」入口**，随时能重看
18. **数据导出被拒后可换个位置重试**（不用退回上一步重来）

## 修复

19. **规划规则页改动会被静默丢掉**：二十多个输入框只在点「保存设置」时落库，此前**返回、点侧栏、关窗口都会丢**——现在离开前先问一句，默认那一侧是「继续编辑」，没改过则不弹框
20. **今天做完的事在今日与日历界面消失**：勾选完成触发重排，已完成任务不再参与排程，新版本计划里没有它的时间块——现在会补上已结束任务在过去时间里的块，带完成标记
21. **统计页「自定义范围」常亮**：按钮写死成实心，选哪个范围亮的都是它——现在选哪个哪个亮
22. **同一领域在不同页面颜色不一致**：统计页自己另编色板按"排在第几个"取色——现在四个页面走同一取色规则
23. **饼图切片上白字看不清**：最浅一色只有 **1.85:1**（标准 4.5:1），换深色也有两色不达标——改为切片上不写字、图表下方给图例
24. **课表导入报系统错误文本**：不再出现 `PathAccessException`、`OS Error 5` 这类字样
25. **备份失败时泄漏本机完整路径**：Dart 文件异常的 `toString()` 带着绝对路径——现在替换成人话，同时保留"拒绝访问""网络名不再可用"这类有用信息
26. **任务页「已完成」永远是空的**：此前只读未结束的任务，现在读取全部任务
27. **新建任务页保存失败静默留在原页**：现在明确指出来
28. **日期与时间选择器是英文且看不清**：已中文化，选中日与"今天"的对比度修好
29. **周数与第一周日期换算的边界**：补齐跨年、学期中途、非法日期
30. **统计自定义范围的边界**：末日的当天要包含、单日、跨月、跨年、12/31、闰年 2/29
31. **时间轴在 150% 缩放下不可用**：现在可以操作

## 引导的四状态（行为约定）

32. **中途退出不算完成**：返回 / 关窗口 / 崩溃都保留进度，下次启动继续问
33. **「暂时跳过」只跳过这一次**，下次启动还会问
34. **「跳过引导」以后不再自动弹**
35. **「重新开始」只重置引导进度**，已建任务、导入课表、已确认计划一个都不删
36. **引导里建的任务就是普通任务**：同一张表、同一套默认值与校验，能编辑/删除/完成/拆分/重排，统计与日历照常显示，**无隐藏标签、无特殊类型**
37. **引导的规划窗口是「本机今天零点起 7 个自然日」**，例如 10-07 进引导 → `10-07 ～ 10-13`
38. **不硬把任务塞进今天**：今天太晚、没空档或不满足最早开始时间时，第一个任务排到明天或之后
39. **重新打开引导按当天日期重算**，不沿用旧日期

## 打磨

40. **引导首页文案会看情况**：已经用过就写「**再创建一个任务**」，不假装你是第一次
41. **新建任务页分区更清楚**，「更多选项」默认收起
42. **引导里未确认的表单与预览退出时丢弃**，不会被当成真实计划落库

## 已知限度（如实说明）

- **时间轴模式里不能拖动**。拖动移动只在「紧凑」模式可用——"拖到几点"与"拖到哪一天"不是同一套语义，没有随手发明它
- **时间轴只画你有安排的时间范围**（例如 9:00–21:00），不能滚动到整天完全没有安排的时段
- **引导的三个入口复用既有页面**，不是引导专用的简化流程。这是刻意的：引导里建的任务必须与你平时建的任务完全一样，所以走同一条路
