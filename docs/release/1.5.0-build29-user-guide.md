## 统计复盘：这一版变成了什么

**页面从上到下**：

1. **领域占比**（横向）——所选范围里时间分给了哪些领域。
   👉 **现在把固定日程算进去了**。上一版只统计任务计划块，你的课表（每周 20 多小时、几乎全是学业）
   完全没被算，占比是失真的。脚注会写明每个领域"计划 X 分钟 + 固定日程 Y 分钟"。
2. **时间总计**（纵向）——上周 / 本周 / 本月各自的总占用，下面是逐领域 × 逐周期的矩阵表
   （每格给分钟数与该周期内的占比）。
3. **完成情况 + 领域覆盖缺口**——完成率、按期完成、**逾期率**（此前一直算出来却没显示），
   以及**哪些领域在范围内一个计划块、一场固定日程都没有**。你库里 科研／竞赛／工作 目前是零占用，
   这正是"规划合不合理"最直接的证据。
4. **休息**——三张卡，全部按**你自己的规划**算：
   - **休息时长**：睡眠／午餐／晚餐／固定休息各有多少时间，其中多少被安排占用（达成率）。
   - **工作与休息的比例**：工作·学习 / 生活 / 空着的休息 / 未安排 四段划分。
     "空着的休息"是减去被安排占用之后的，所以把任务排进睡眠不会让报表显得"休息充足"。
   - **作息规律性**：每天开工与收工时刻，以及它们的**极差**（相差越大越不规律）与平均时刻。
5. **中断与调整**——常见中断、重排原因、建议采纳（原样保留）。

### 图表类型由你选

每张图右上角可以切换类型：**饼图 / 柱状图 / 条形图 / 折线图**。可选项按数据形状给——占比类不提供
折线（会让人以为它在讲趋势），时间序列不提供饼图。**你的选择会被记住**（存在设置里），下次打开
还是你选的样子。

### 已按你的要求移除

"计划 / 实际"整组：计划与实际的分钟数卡、计划/实际对比图、每日趋势、预估偏差、生活配额，
以及旧的"精力时段完成效果"和"休息保护情况"两行。

> **顺带说明**：这不只是少画几张图——`FR-STAT-03／09` 原本是规格里的硬性要求（"展示计划时长、
> 实际投入…"、"明确区分计划数据与实际数据"）。按规格 §20 的规定，**改变统计口径必须重新获得
> 明确确认并更新文档**，所以这次偏离已经写进规格 §8.9.1，人工验收清单 7.3 也一并改了。
> **专注计时、补录、导出（导出仍然区分计划与实际）都没有动**——只有统计页不再展示这一侧。
