# 优计主义 1.11.1 更新

1.11.1 是一次缺陷修复版本，专门修复更新检查里的三个问题。它没有新增功能，也不改变你的任务、
计划与课程数据。

## 已修复的三个问题

**1. 明明有新版本，却显示“已是最新版”**

在 1.10.x 上，程序发现并下载 1.11.0 之后，如果后台又在准备安全回退包，两个版本的清单可能
互相覆盖。之后一次“没有变化”的检查会把旧版本当成最新版本，于是设置页显示“已是最新版”，
安装入口消失。现在最新版本与历史版本的清单分开保存，互不覆盖；已经下载并验证过的更新包
不会因为一次过期的检查结果被丢弃。

**2. 回退准备卡住，安装入口一直无法使用**

安全回退包（回退基线）准备失败后，旧版本不会自动恢复，安装入口会一直停在“无法安装”。
现在回退准备失败会自动重试，网络恢复后也会自动继续；点“重试准备”不会再重复下载或产生
多个并发任务。

**3. 重启后，已经下载的更新目标丢失**

旧版本在重启后只读取状态文件。状态文件被清空或降级时，磁盘上已经下载并验证过的更新包
不再被识别，用户既不能安装，也看不出原因。现在启动时会复核磁盘上的更新包，验证通过的
会继续保留并可用于安装。

## 如果你正卡在旧版本

1. 打开本 Release 页面，下载 `BestPlanning_Setup_1.11.1_x64.exe`；
2. 双击运行，按提示完成安装。**覆盖安装即可，不需要先卸载**；
3. 安装完成后正常启动。首次启动会迁移旧的更新缓存与状态。

**不需要**做这些事：手工删除缓存文件、编辑 JSON、运行 PowerShell 脚本、手工导入证书。
安装器会保留你的任务、计划、课程、设置与历史记录。

## 兼容性

- 应用版本为 `1.11.1+53`，MSIX 版本为 `1.11.1.0`
- 数据库 schema 仍为 `11`，排程算法版本仍为 `20`：本次没有数据结构或算法变更
- 包身份、发布者与包族名不变，可以直接覆盖升级
- `1.10.x` 与 `1.11.0` 的安装版都可以用上面的 Setup 覆盖安装

## 文件校验值

以本 Release 附件中的 `SHA256SUMS.txt` 为准（四个产物的 SHA-256）。如果校验值与附件不一致，
请不要安装并联系维护者。

## 已知限制

- 便携版没有 Windows 包身份，不参与应用内自动更新，也不会注册系统通知
- 同版本的“修复安装”只重新登记应用，不会替换已经损坏的文件；文件损坏时需要先卸载再安装
- Microsoft Store、差分补丁和其他桌面系统不在本次范围内
- 安装包需要 Windows 10/11 x64

安装：下载 `BestPlanning_Setup_1.11.1_x64.exe`，双击后按提示完成安装。
