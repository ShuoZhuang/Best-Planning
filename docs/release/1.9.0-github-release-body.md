# 优计主义 1.9.0 更新

1.9.0 更换了 Windows 更新方式。软件不再只检查 GitHub 后打开浏览器，而是能在后台下载、核对并安装后续正式版本。

## 这一次需要手动安装

- `1.8.1` 及更早版本还没有新的更新组件，因此无法自动升级到 `1.9.0`
- 请下载 `BestPlanning_1.9.0.0_x64.msix`，完全退出旧版和托盘图标后再安装
- 从 `1.9.0` 开始，后续正式版本可以由软件在后台下载；是否安装仍由你决定
- 已通过官方安装包使用优计主义的用户已经信任同一张签名证书，可以直接覆盖安装

## 后台下载，不打断使用

- 软件会读取固定地址上的签名更新清单，不再依赖 GitHub Releases API 猜测最新版
- 发现新版本后自动在后台下载，支持断点续传；网络中断后不用从头开始
- 下载过程中不弹窗、不打开浏览器，也不会自动退出或安装
- 下载完成后，左下角会出现更新入口；点击后才开始安装
- 自动更新关闭时仍可以手动检查和下载

## 下载和安装前会逐项核对

- 更新清单使用 Ed25519 签名，字段缺失、多出未知字段或签名不符时会直接拒绝
- 安装包会核对文件大小、SHA-256、MSIX 签名、发布者、包身份、架构和版本
- 下载地址只允许使用 Best-Planning 官方 GitHub Release 及 GitHub 官方资产域名
- 被撤回、版本倒退或身份不一致的安装包不会进入安装流程

## 更新时保护正在编辑的内容

- 新建或编辑任务、周期目标、固定日程、保护时间、课程和规划规则时，更新入口会保留但暂时不可点击
- 页面会提示先保存或取消当前编辑，不会替你自动保存，也不会丢弃草稿
- 只查看详情不会被误判为未保存编辑；专注计时也不会阻止更新
- 正在写入数据库时会等待本次操作完成，再允许安装

## 安装失败可以恢复

- 安装前会保存数据快照，并保留上一版的安装包作为回退基线
- 独立更新助手会等待主程序和托盘完全退出，再执行 MSIX 原位升级
- 新版本启动后需要通过健康检查；安装、启动或健康确认失败时，系统会在安全条件满足时恢复上一版和更新前数据
- 同一目标连续失败三次后会暂停自动尝试，等待你手动重试，避免循环安装

## 更新状态和诊断

- 设置中的更新页面会显示检查、下载、验证、等待安装和失败状态
- 网络失败与「已经是最新版」现在明确区分，不会因为请求失败而显示假成功
- 更新日志只记录阶段、版本、校验结论和 Windows 错误码，不记录任务标题、备注或数据库内容

## 数据与兼容性

- 应用版本为 `1.9.0+46`，MSIX 版本为 `1.9.0.0`
- 包身份仍为 `ShuoZhuang.PersonalPlanner`，可以覆盖安装 `1.8.1`
- 本次没有修改业务数据库结构，任务、计划、课程、设置和历史记录都会保留
- 升级前仍建议从**设置 → 数据与帮助 → 数据备份与恢复**保存一份备份

## 已知限制

- 自动更新目前只支持 Windows x64 的 MSIX 安装版，便携版仍需手动下载新版本
- `1.8.1` 及更早版本没有新更新组件，因此升级到 `1.9.0` 这一次必须手动完成
- 用户必须点击更新入口才会安装；软件不会静默退出或强制升级
- Microsoft Store、差分补丁和其他桌面系统不在本次范围内

安装：下载完整 ZIP，解压后**双击「安装.cmd」**即可。
