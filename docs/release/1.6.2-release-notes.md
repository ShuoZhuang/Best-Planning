## 一句话

任务怎么排、今天是哪几件事、时间花在哪、设置在哪改——这四件事此前各自能用但**接不起来**；
本轮把它们接成一条闭环，并修掉若干"不报错但结果不对"的缺陷。

## 值得单独说的三件事

### 1. 「跳过本次」不是「延后到明天」

今天这一块做不了时，你会想"那就先跳过它"。此前的选择只有"延后到明天"——而明天未必合适。

现在**三个动作是分开的**：

| 动作 | 含义 |
| --- | --- |
| **跳过本次** | 只丢掉**今天这一块**；任务仍然是待办，剩余时间不变（只扣真实专注过的部分），系统**重新找一个合适的空档**——可能是今天晚些时候、明天，也可能是别的天 |
| **延后到明天** | 明确把可用时间推到明天 |
| **取消任务** | 任务本身作废 |

系统重找时间时**默认先给你看调整预览**，只有你开了「信任自动调整」才直接应用。
如果实在排不下，它会明说"待安排／有逾期风险"以及差多少，而不是硬塞。

### 2. 七日日历多了一个「时间轴」模式

按**真实时间比例**排列：一小时就是一小时那么高。同时进行的事**并排**显示，不会一个盖住另一个。

隐藏在这一条下面的技术点值得一提：像 9:00–11:00、9:30–10:00、10:30–11:30 这种**交叉重叠**
（首尾两块也重叠）必须排成**三列**，而"找个空位放下"的常见写法会给两列、然后两块左右压在一起。
这里是按**团**算的，因此画面不会骗你。

紧凑模式**完全保留**，选择会被记住。

### 3. 统计页的领域颜色，现在和其它页面一致了

这是个你**看得见但很难说清**的毛病：统计页「领域占比」里"学业"的颜色，
和今日页、日历页里"学业"的颜色**不是同一个**。

原因是统计页自己另编了一套色板、按"排在第几个"取色。
现在四个页面走**同一个取色规则**，两张图终于能对上。

图表本身也改了：饼图切片上原来写着白色标签，而有些切片底色太浅、白字几乎看不清
（实测最浅的一色只有 **1.85:1**，而可读标准是 4.5:1；换成深色**也不行**——
有两种颜色放深色同样不达标）。现在**切片上不写字，图表下方给图例**：

```
■ 学业 120   ■ 科研 90   ■ 生活 60
```

## 全部改动

### 任务与分类（M1、M2、M3）

- 任务清单新增「**全部／待安排／已安排／已完成**」筛选，带数量、可用键盘切换、窄窗可横向滚动。
- 每张卡片显示**真实状态**：`待安排 · 预计 50 分钟` / `已安排 · 13:00–14:30` /
  `已完成 · 实际投入 25 分钟`，逾期再加「已逾期 · 截止于…」。
- 任务页改为读取**全部**任务（此前只读未结束的，因此"已完成"永远是空的）。
- 新建任务页：更清楚的分区，「更多选项」默认收起；**保存失败/缺字段会明确指出来**，
  而不是静默留在原页。
- 日期与时间选择器中文化，选中日与"今天"的对比度修好。

### 今日执行与重排（M4）

- 「跳过本次」按上面第 1 点实现，三个动作互相独立。
- 计划预览把变更分成 **新增／移动／拆分／未安排／保护时间变化**，
  并给出原时间与目标时间。

### 周日历（M5）

- 新增「紧凑／时间轴」切换，默认**紧凑**（不强迫你接受新密度），选择会记住。
- 时间轴按真实比例绘制，重叠**并排**，显示真实起止时间，长标题省略并可悬停看全。
- 150% 缩放下仍可操作。

### 课表导入（M6）

- 图片读不出来时说清**是哪张**（文件名，不含目录路径）、**支持哪些格式**（PNG/JPG/JPEG），
  并在失败处**就地**给「更换图片」。
- 再也不会看到 `PathAccessException`、`OS Error 5` 这类系统文本。
- 周数与第一周日期的双向换算补齐**跨年、学期中途、非法日期**测试。

### 统计与复盘（M7）

- 同一领域在今日、日历、统计三个页面显示**同一个颜色**。
- 图表四档材质下通过对比度检查（文字 ≥ 4.5:1、图形 ≥ 3:1），并给出可读**图例**。
- 自定义日期范围的边界补齐测试：**末日含当天**、单日、跨月、跨年、12/31、闰年 2/29。

### 设置与引导（M8）

- 设置首页按**规划与时间／外观与交互／通知与隐私／数据与帮助**四组分区；
  每个入口右侧显示**当前值**（例如"默认专注 50 分钟"、"材质：克制"）。
- **修掉一个真问题**：规划规则页有二十多个输入框，改动只在点「保存设置」时才落库，
  而此前**返回、点侧栏、关窗口都会静默丢掉**。现在离开时会先问一句，
  默认那一侧是**继续编辑**；没改过东西时不会弹框。

### 数据安全与发布（M9）

- 同时交付便携目录、ZIP、已签名 MSIX、公钥证书、安装脚本、安装说明、SHA-256 与用户指南。
- MSIX 签名 `Valid`，版本 `1.6.2.0` **严格高于**上一版（`1.6.2.0` / `1.6.1.0`），可**原位覆盖安装**。
- 修掉一处**会泄漏本机路径**的缺陷：备份失败时兜底分支原先把异常原样打印，
  而 Dart 的文件异常 `toString()` **带着完整路径**（例如
  `FileSystemException: ... path = 'F:\Documents\personal_planner.sqlite' ...`）。
  现在会把路径替换成人话占位，同时**保留"拒绝访问""网络名不再可用"这类有用信息**。

### 4. 收口后又按实测反馈修的两处

这两处是**在你实测之后**发现并修掉的，因此 MSIX 版本是 1.6.2.0：

- **今天做完的事在今日和日历界面消失**：勾选完成会触发重排，而已完成的任务不再参与排程，
  于是新版本计划里没有它的时间块；视图那条"当天只看当前版"的规则让今天正好命中。
  现在会补上**已结束任务在过去时间里的块**——今天做完的事仍然显示在做它的时间，
  带完成标记。
- **统计页「自定义范围」常亮**：那个按钮写死成实心，所以不管你选「今天」「本周」还是「本月」，
  亮着的都是它。现在**选哪个哪个亮**。

## 已知限度（如实说明，不是"已修好"）

- **时间轴模式里不能拖动。** 拖动移动仍只在「紧凑」模式可用——"拖到几点"与"拖到哪一天"
  不是同一套语义，我没有随手发明它。
- **时间轴只画你有安排的时间范围**（例如 9:00–21:00），不能滚动到整天完全没有安排的时段。
- **首次引导仍是"确认默认值"**，采用完默认值后你还是面对一个空的应用。
  「不离开引导就完成第一个计划」**尚未实现**——它需要先定几个产品问题
  （引导中途退出算不算完成、跳过后再打开是重放还是直接进编辑器等），
  未定清就写只会再造成一条与真实操作脱节的引导。
- **通知点击的真实交互**仍需人工验证一次（自动化无法覆盖到系统通知中心的那一下点击）。
