## 1. 日期选择器右上角那两个按钮

你截图里那个飘着的 **`Save`** 就是它。查下去发现是**两个原因叠在一起**：

| 原因 | 现象 | 修法 |
| --- | --- | --- |
| 全局 `textButtonTheme` 用的是次要灰 | 在深色面板上几乎看不见 | 选择器套一层高对比主题：主文本色 + 可见填充与描边（对比度 12:1） |
| **应用没配 Material 中文本地化** | 按钮显示英文 `Save`、月份显示 `October 2026`、星期显示 `S M T W T F S` | 加 `flutter_localizations` 并钉死简体中文；全屏模式的保存文案也显式给成「应用」 |

顺带修了**同一类**问题：全库 9 处日期/时间选择器（统计范围、任务到期日、执行时间、学期日期、节次时间…）
全部套上同一层主题——它们继承的是同一个缺陷。

## 2. 七日日历：昨天 / 今天 / 明天，然后周几

按你说的做成横向日期条：**最左是昨天**（可往回看），今天用主色框标出，接着明天，再往后是周几。
订阅窗口也跟着左移一天——否则昨天那一列永远是空的，看起来像"昨天没有安排"。

## 3. 设置页底部显示软件版本号

设置页最下方一行「软件版本 1.5.0+32」。数值来自源码常量，且由一致性测试守着，不会和 `pubspec.yaml` 漂移。

## 5. 重排之后，过去已完成的计划不再消失（你报的那条）

成因：日程视图只读**最新一版**计划，而重排会新建版本——过去几天当时排了什么，只留在旧版本里，
于是"重排一次、历史全没"。

修法：把**所有版本**里落在窗口内、且**已经发生**的块一起读回来（未来时段仍以最新计划为准，
否则"把任务改到别的时间"会同时显示新旧两个位置）。已经发生的事不再被后来的计划改写。

## 6. 紧接着的重复问题（我在上面那个修复里引入的）

你说"为什么现在的已完成待办有重复的"——**是我引入的**：重排与撤销会给同一个安排**分配新的块 id**，
而我按 id 去重，于是同一件事从新旧两版各出现一次。

已改为按 **(任务 + 开始时刻)** 去重（同一任务不可能同时出现在两个位置），并保留当前版本那一条。
回归测试做了 RED 验证：去掉键去重立刻重复成 2 条，正是你看到的现象。
