## 安装或升级

解压整个文件夹，**双击 `安装.cmd`**（弹一次 UAC 选"是"）。它会自动：

1. 把签名证书装进「本地计算机 → 受信任人」；
2. 安装或**原位升级** MSIX（当前 `1.5.0.6`）；
3. 报告结果，之后可从开始菜单打开。

升级时重复同样操作即可：证书已受信任会自动跳过，不会重复导入。

> 便携版则解压后直接双击 `personal_planner.exe`，**不需要证书、不需要管理员**（可能弹一次
> SmartScreen，点"更多信息 → 仍要运行"）。

> **本版第一次启动会先弹「新手教程」**（七步、真实界面截图）。之后想重看：**设置 → 新手教程**。

## 为什么会有这一版：一个截图里的旧 bug

复核教程时发现「今日」那张截图是**在 `1.5.0.3` 上拍的**，而那个版本正好有"已完成待办重复"的缺陷——
截图里 `算法作业` 出现 **3 次**（07:30、07:30、10:00）。把一个**已经修好的 bug 印进教程**，比截图
过时严重得多：用户会以为那是正常效果。所以重拍并重新打包。

修复前的图保留为证据：`evidence-1.5.0-build33-BEFORE-duplicate-fix-today.png`（你可以在
`release` 目录里直接对比看）。

## 这一批（1.5.0）当前包含的改动

### 已完成待办重复——**修法换过一次，因为第一版规则本身是错的**

| 你的实际数据 | 并集式的错误后果 |
| --- | --- |
| `算法作业` 今天在当前版是 **10:00**、旧版是 **07:30** | 今天出现 **2 次** |
| `大物预习课`（已完成）旧版 **50+90 分钟**、新版 **90+50 分钟** | 当天出现 **3~4 次** |

现在的规则是：**一个本地日只由一版计划决定**——当天当前版本有安排就只用当前版本；当天当前版本没有
安排、且这一天已经完整过去，才用"当天结束时在用的那一版"还原。依据是**一版计划是对那段时间的完整
声明**，跨版本求并集在语义上就是错的。

### 选择统计范围的日历区恢复透光

上一版为修按钮对比度把选择器底色写成了**不透明**，透光就没了。现在只改对比度、不改透光（底色从当前
玻璃模式取色）。

### 日期／时间选择器看得见、也是中文

根因有两个：全局 `textButtonTheme` 用的是次要灰（那个飘着的 `Save` 就是它），以及**应用从未配置
Material 中文本地化**（按钮显示 `Save`、月份显示 `October 2026`）。全库 9 处选择器一次修到这一类。

### 七日日历：昨天 / 今天 / 明天，然后周几

`昨天 10月6日 ｜ 今天 10月7日（主色高亮）｜ 明天 10月8日 ｜ 周五 ｜ …`
