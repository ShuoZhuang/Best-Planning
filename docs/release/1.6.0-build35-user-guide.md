# 智能日程 1.6.0+35（开发构建／待验收）

本文件是**当前**的使用说明（取代 `1.5.0-build34-user-guide.md`）。相对上一版，这一版做了一件新事：
**任务页可以按状态筛选了，而且每张卡片都写清了自己的状态**。

## 安装或升级

解压整个文件夹，**双击 `安装.cmd`**（弹一次 UAC 选"是"）。它会自动：

1. 把签名证书装进「本地计算机 → 受信任人」；
2. 安装或**原位升级** MSIX（当前 `1.6.0.0`）；
3. 报告结果，之后可从开始菜单打开。

升级时重复同样操作即可：证书已受信任会自动跳过，不会重复导入。

> 便携版则解压后直接双击 `personal_planner.exe`，**不需要证书、不需要管理员**（可能弹一次
> SmartScreen，点"更多信息 → 仍要运行"）。

> **本版第一次启动会先弹「新手教程」**（七步、真实界面截图）。之后想重看：**设置 → 新手教程**。

## 这一版的新东西：任务页的状态筛选

打开「任务」，搜索框下方多了一行筛选：

```text
[ 全部 8 ] [ 待安排 2 ] [ 已安排 4 ] [ 已完成 2 ]
```

- **全部**：你能看到的全部任务（＝ 待安排 ＋ 已安排 ＋ 已完成）。
- **待安排**：还没进入当前计划的任务。刚建好还没生成计划、原来安排的时间已经过去、
  或者逾期之后还没有补排，都会在这里。
- **已安排**：**当前计划里还有一段没结束的时间**的任务。正在进行中的、逾期但已经补排到未来的、
  被拆成几段且至少一段还没结束的，都算。
- **已完成**：做完的任务。它们会一直留着，随时可以取消勾选把它改回"待安排"。

数量是**跟着数据实时变的**，而且搜索**不会**改变这些数字——搜完只剩一条时，筛选栏仍然显示
全量的 `全部 8　待安排 2　已安排 4　已完成 2`，这让你知道自己是在多大的一堆里搜。

### 每张卡片都会告诉你它现在是什么状态

```text
算法作业
待安排 · 预计 50 分钟

大物预习课
已安排 · 13:00–14:30

竞赛报名
已完成 · 实际投入 25 分钟

大物作业
已逾期 · 待安排 · 截止于 10月6日 23:59
```

几条口径说清楚：

- **"已逾期"是提醒，不是第四种类别**。逾期但已经补排到未来的任务会显示
  `已逾期 · 已安排 · 21:00–22:00`——它确实逾期过，而现在的安排是有效的。
- **已经过去的时间段不算"已安排"**。昨天排的计划不会让今天还显示"已安排"，
  它会回到「待安排」等你重新安排。
- **卡片颜色仍然是领域色**，不会因为状态而换色——颜色表示"这件事属于哪个领域"，
  状态用文字说。

### 空列表也会说清为什么空

以前无论哪种情况都显示"暂无匹配任务"，现在分开说：

| 你看到的 | 意思 |
| --- | --- |
| 还没有任务 | 一条任务都还没有，旁边有"新建任务" |
| 没有待安排任务 | 进行中的任务都已经进入计划了 |
| 没有已安排任务 | 当前计划里没有任务，旁边有"生成计划" |
| 还没有已完成任务 | 还没有做完过任何事 |
| 没有找到"×××" | 搜索没命中，旁边有"清除搜索条件" |

### 多选

- 「待安排」「已安排」「全部」都能进多选。
- 「全部」里**已经完成的任务不能勾选**（要改就把筛选切到「已完成」）。
- 「已完成」这一栏不显示"多选"按钮。
- **切换筛选会自动退出多选并清空已勾选的任务**——避免你对着看不见的任务执行批量操作。

> 「已取消」和「已跳过」的任务**不会出现在这四个筛选里**，但它们的数据一条都没有被删除，
> 将来会有一个单独的"归档任务"入口来查看。

## 版本号说明

**`1.5.0` → `1.6.0`（抬第 2 段）**：这一批含**用户可感知的新功能**，按版本规则第 2 节抬 Minor；
它向后兼容（**没有数据库结构变更、没有迁移、没有改包身份**），所以不是 Major。

**为什么不再并入 `1.5.0`**：`1.5.0.6` 已经交给你做体验确认了，而"同一批次只加构建号、只动第四段"
的前提是这一批**还没到任何人手上**。前提不成立，加上内容本身是新功能，于是开新批次 `1.6.0`，
第四段回到 `0`，构建号继续递增到 `+35`。
