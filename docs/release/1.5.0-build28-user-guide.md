# 智能日程 1.5.0+28（开发构建／待验收）

本版**新增「领域时间分配」视图**——统计复盘不再以"计划 vs 实际"为主，而是回答"我的时间分给了哪些
领域、跟上周比有什么变化"。同时修掉上一版你发现的两处问题。

## 安装或升级

1. 如果“智能日程”正在运行，请先退出程序；必要时在任务栏托盘图标菜单中选择退出。
2. 双击 `PersonalPlanner-1.5.0-build28-windows-x64-20261006.msix`。
3. 选择“安装”或“更新”。本版 MSIX 版本为 `1.5.0.0`，可以**原位覆盖**本机已有的 `1.4.2.5`
   及更早的版本（不需要先卸载，现有任务、领域颜色、课表和设置都会保留）。
4. 安装完成后，从开始菜单启动“智能日程”。

如果 Windows 提示证书不受信任，请先安装同目录的 `PersonalPlanner-signing-cert.cer`（安装证书 →
当前用户 → 放入“受信任人”）。证书主题应为 `CN=Shuo Zhuang, O=Personal User, C=CN`，指纹
`9E157ECE535D16A224593CA39C084705A4FD3C13`。

> **版本只能往上走**：Windows 不接受比已安装版本更低的安装包。

## 本次变化

### 1. 统计复盘新增「领域时间分配」（本版的重点）

统计页**最上面**现在是一张「领域时间分配」：

- **上面是堆叠柱**：上周、本周、本月各一根柱子，按领域分段。一眼能看出"这周时间都去哪儿了"，
  以及跟上周比哪一块涨了、哪一块掉了。
- **下面是矩阵表**：行是领域，列是周期，每个格子给出**分钟数**和它在该周期里的**占比**，
  最后一行是各周期合计。

**口径只算已确认的计划块**，不含实际投入——这是按你的要求定的。原来那张按实际投入统计的
「领域分布」饼图已移除：两个都叫"领域分布"却数字不同，摆在一起只会让人怀疑哪个是真的。
领域视角现在只有矩阵这一个入口。

「计划 / 实际」与「每日趋势」两张图仍然保留，但位置降到矩阵下面，作为次要视图。

### 2. 勾选完成后，卡片不再变成「已安排任务」

上一版你看到的现象：勾完成后卡片标题变成「已安排任务」、分类变成「无领域任务」，**颜色也跟着变**。
根因是日程数据源只从"未结束任务"里查标题与领域，任务完成了但计划块还在，于是查不到、走了兜底分支。
现在会补查一次，**保留真实标题与领域颜色**。

### 3. 新增「已完成」标记（上一版）

- **任务**：勾选完成后，它的计划块在今日、七日日历、单日详情里都带一个对勾标记；
- **固定日程**：结束时间过去后，同样带这个标记（固定日程没有"勾选"这个动作，它的完成就是时间过去）；
- **保护时间不标记**：它不是待办。

### 4. 「领域与项目」页的卡片不再贴在一起（上一版）

领域、特殊日程颜色、项目三处列表的卡片此前圆角边框直接贴在一起，现在相邻卡片之间留出 8px。

## 便携版

保留本目录内全部运行文件，然后双击 `personal_planner.exe`。不要只把 EXE 单独复制出去；它依赖同目录
的 DLL 和 `data` 文件夹。

## 版本号说明

本版从 `1.4.2` 抬到了 `1.5.0`：`1.4.2` 是"只有修复"的补丁批次，而本版**含用户可感知的新功能**
（领域时间分配），按版本规则应当抬第 2 段。`1.4.2` 期间的全部改动（卡片配色、已完成标记、间距修复）
从未对外发布，随本版一起交付。

## 版本状态

这是开发构建，尚未登记为正式发布。请先体验：统计页的领域时间分配是否符合你要的横向纵向对比、
三个周期（上周/本周/本月）是否合适、以及"已完成"标记是否清楚。
