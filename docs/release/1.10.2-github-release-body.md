# 优计主义 1.10.2 更新

这是一个**修复版本**：修好了 `1.10.0` / `1.10.1` 单文件安装器在"这台电脑还没信任过发布证书"
时无法完成首次安装的问题。应用本身没有功能变化，数据不需要迁移。

## 修了什么

`1.10.0` / `1.10.1` 的单文件安装器在首次安装时可能停在这一步：

```text
failure INSTALLER_CERTIFICATE_IMPORT_FAILED detail=pipe-connect-timeout
result FAILED_BEFORE_CHANGE
finalState NotInstalled
```

预检和安装包校验都是通过的，失败发生在"请求一次管理员授权、把发布证书写进
本地计算机 → 受信任人"这一步：安装器的普通权限主进程与管理员辅助进程之间的管道通信
没能建立起来。**这不是证书有问题，也不是证书已经被写入后失败**——失败时系统里什么都没改。

`1.10.2` 的修复：

- 管道改成真正的异步（overlapped）模式，等待与取消都有确定行为，不再靠"等更久"
- 辅助进程不再依赖"直接父进程 PID"判断身份；身份由启动时返回的进程句柄与管道实际连接者的
  PID 共同确定，跨账户凭据与 UAC 中介都能正常工作
- 管理员辅助进程提前退出时立即报出真实退出码，不再苦等三分钟、也不再谎报"连接超时"
- 协议版本升到 `2`；管道名后缀必须与一次性随机串完全一致，握手字段逐项核对
- 错误提示分层：**未获授权**、**安全通信失败**、**证书写入失败**是三条不同的信息，
  不再把"没连上"说成"证书写入失败"
- 安装完成页的「完成」按钮不再失效；安装成功后安装器的退出码是 `0`
  （修复前会报 `99`，即"装成功了却说自己内部错误"）

## 谁需要升级

- **准备新装或换机安装**：请使用本版本的单文件 Setup。
- **已经用 `1.10.0` / `1.10.1` 安装成功**：不需要卸载，也不需要重装。应用内更新会照常
  通过 MSIX 升级到 `1.10.2`。
- **在 `1.10.0` / `1.10.1` 上首次安装失败**（`finalState NotInstalled`）：直接运行
  `1.10.2` 的单文件 Setup 即可。

## 验证仍然逐项完成

- 主程序与管理员辅助进程各自从只读资源重读安装包并校验大小、SHA-256、数字签名、
  发布者、包身份、架构与版本
- 辅助进程只接受一条固定命令（校验并信任内嵌证书），只写
  `本地计算机 → 受信任人`，不接受任意路径、脚本、存储区或任意命令
- 管道只允许原始用户、`SYSTEM` 与管理员连接，并拒绝来自网络的连接
- 安装包仍由**发起安装的那个用户**部署；标准账户在 UAC 里输入另一位管理员的凭据时，
  应用仍然登记给标准账户，不会跑到管理员名下

## 数据与兼容性

- 应用版本为 `1.10.2+51`，MSIX 版本为 `1.10.2.0`
- 包身份、发布者与数据库结构与 `1.10.0` / `1.10.1` 相同，不需要数据迁移
- 任务、计划、课程、设置、偏好和历史记录都会保留
- 从 `1.10.0` / `1.10.1` 可以直接覆盖升级；升级前建议先保存一份数据备份

## 已知限制

- 同版本的「修复安装」只重新登记应用，不会替换已安装文件；文件损坏需要先卸载再安装
- 便携版没有 Windows 包身份，不参与自动更新，也不会注册通知
- 本次发布**只修安装器的 UAC 通信**：应用功能、排程算法与自更新下载逻辑都没有改动
- Microsoft Store、差分补丁和其他桌面系统不在本次范围内

安装：下载 `BestPlanning_Setup_1.10.2_x64.exe`，双击后按提示完成安装。
