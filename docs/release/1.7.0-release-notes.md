## 这一版做了什么

`1.7.0` 在一个发布批次里重做统计复盘、修正日程详情导航、加入按周固定时长的周期目标，
并提供默认开启的更新检查。

### 1. 统计复盘（原"统计"页）

- 页面名称改为**"计划复盘"**，主标题改为**"看看时间是怎么安排的"**。
- 默认范围改为**"本周"**；"今天 / 本周 / 本月 / 自定义范围"都以当前本地日期实时计算，
  **程序跨过午夜后自动刷新"今天"**，不会继续显示昨天。
- 首页先给四项摘要：**计划总时长、任务完成率、保护时间达成率、最需处理的问题**。
- 主体分为四个页签：**时间分配、计划质量、休息与作息、调整记录**。
- 时间分配默认使用**按时长降序的横向条形图**，显示"小时 + 分钟"和百分比；横轴按范围抽样，
  周范围按日、月范围按周、长范围按月聚合，标签不超过 6～8 个。
- 空白时间叫**"可用空闲"或"未安排"，不再叫"休息"**；只有明确的保护时间才计入休息。
- 每个摘要、比例和图表项都能**打开来源明细**，再从明细进入任务或日程。
- 去掉主路径上的"任意切换图表类型"；每项指标使用固定且适合其含义的图形。
- **周期目标进度单独展示**，不混入领域时间分配，也不冒充完整的实际投入统计。

### 2. 日程详情导航

- **任务**进入任务详情页；**固定日程**进入对应日期并定位该日程；**保护时间**进入规划规则页。
- 没有合法目标的事项**不显示死入口**（此前对不存在的任务 ID 使用了强制解包）。
- 点击卡片主体打开详情；"更多"菜单只放完成、跳过、调整、锁定等动作。
- 返回后保留来源页、选中日期与滚动位置；编辑成功后来源页立即刷新。

### 3. 每周周期目标（按周完成固定时长）

- 新建入口提供四种清楚的去向：**普通任务、周期目标、固定日程、保护时间**。
- 模板定义每周目标分钟、领域、项目、优先级、精力、拆分方式、片段长度、期望时段和安排节奏
  （**均匀分布（默认）、尽早完成、临近截止、仅指定星期**）。
- 每周生成**一个普通任务实例**，继续沿用现有任务详情、专注记录、计划块和重排能力。
- 数据库以**"模板 ID + 周期开始日期"**为唯一键：重复启动、恢复备份或跨周刷新都不会重复生成。
- 每周实例独立记录目标、已完成分钟、剩余分钟与结果；**达标后不抵扣下一周**。
- 专注计时与手动补记都计入本周进度；超过目标可以保留记录，但**排程剩余量最低为 0**。
- 不足目标就点"完成"时会**二次确认**；达到目标时提示可以完成本周任务。
- 上周未达标默认**不结转**；"结转未完成分钟"开关默认关闭。
- 支持**跳过本周、仅调整本周、暂停到某日、停止以后生成、从下周修改模板**；
  删除和编辑区分**"仅本周""从下周开始""整个周期"**。
- 卡片显示"本周已完成 80/180 分钟"和"本段 45 分钟"，**不把已安排误写成已完成**。
- 排程以当前周期实例的剩余分钟参与滚动七天规划，**容量不足时返回结构化缺口、不挤占保护时间**，
  并提供处理动作（调低本周目标、放宽期望时段、临时放宽每日上限、允许本周不完全安排）。
- 周期提醒：周四结束前进度低于 50% 提醒一次；距结束不足 24 小时且仍有缺口提醒一次；
  发现容量不足立即生成可处理提示；达标、跳过或暂停后停止本周提醒。

### 4. 更新检查（默认开启）

- 设置里新增更新页，显示**当前版本、自动检查开关、上次检查时间、当前更新源和"立即检查"**。
- 自动检查**默认开启**：启动约 10 秒后检查一次，运行期间最多每 24 小时请求一次；
  关闭后不再发起后台请求，手动检查不受 24 小时限制。
- 程序关闭后不运行定时器，**不创建 Windows 后台服务或计划任务**。
- **只请求 `ShuoZhuang/Best-Planning` 的公开 GitHub Releases 元数据**，忽略 draft 与 prerelease；
  请求带 `User-Agent`、10 秒超时与 ETag，正确处理离线、超时、304、403/429、404 和异常 JSON。
- 有更新时显示**版本号、发布日期、更新说明**和 Release 页面按钮；支持**"跳过此版本"**，
  更高版本仍会提醒。
- `1.7.0` **只打开 GitHub Release 页面，不在应用内下载或执行安装包**。
- 首次进入更新页说明联网边界：**只请求版本信息，不上传本地数据**。
- 运行时版本从**安装包元数据**读取，移除依赖手写常量判断更新的做法。

### 5. 一致性与体验收口

- 完成、跳过本次、修改本周目标和暂停周期都有**撤销入口**。
- 无统计、无确认计划、周期未安排、无更新和数据不足等空状态都给出**下一步操作**。
- 长期横幅不遮挡底部内容，键盘可聚焦关闭按钮，读屏能播报状态变化。

## 数据与兼容性

| 项 | 说明 |
| --- | --- |
| 数据库 | schema v6 → v7，**只新增两张表与索引**（周期目标模板、周期实例），不改写已有 `tasks` / `time_entries` / `calendar_events` |
| 升级前快照 | 打开数据库连接**之前**先用 SQLite backup API 建一次升级前快照（文件名含原 schema 版本与 UTC 时间）；备份失败则**中止升级**并给出可操作错误 |
| 旧数据 | 已有任务、课表、计划与设置保持不变；**无需手工迁移** |
| 本地优先 | 除用户允许的更新检查外，任务、课表、统计、偏好和数据库内容**不离开本机** |
| MSIX | `1.7.0.0`（严格高于已安装的 `1.6.2.0`），可从 `1.6.2` 覆盖安装；卸载与升级**不删除用户数据库** |

## 这一版不包含

- 手机 App、云同步、账号体系或跨设备同步。
- 月度、季度和任意 RRULE 周期；`1.7.0` **只做每周目标**。
- 应用关闭后的后台更新服务。
- 静默下载、静默安装或强制更新。
- 把空白时间推断成休息、把计划时间写成实际投入，或恢复"计划 vs 实际"主视图。
- 重写课程固定日程的 `RecurrenceRules`；固定日程与周期目标保留**两套不同语义**。
