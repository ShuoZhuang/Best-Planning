## 短版（可直接复制给别人）

**智能日程 1.5.0 更新**

- **统计复盘重做**：不再看"计划 vs 实际"，改为**领域时间的横向与纵向对比**——领域占比（含固定日程）、

- **修好了"已完成待办重复"**：同一件事不再因为改过计划而出现多次。
- 日期与时间选择器**看得清、也是中文**了；选择统计范围的日历区恢复原来的透光效果。

安装：解压后**双击「安装.cmd」**即可（弹一次 UAC）。也可以直接用便携版，双击 `personal_planner.exe`。

## 详版

### 一、统计与复盘：换了一套口径

以前这里以"计划 vs 实际"为主。实际投入并没有必要天天盯，所以这一版把它整段去掉，改成回答两个更实际
的问题：**我的时间分给了什么**，以及**我有没有好好休息**。

- **领域占比（横向）**：所选范围里时间分给了哪些领域，**含固定日程**（有领域的固定日程也算进去）。
- **时间总计（纵向）**：上周 / 本周 / 本月的总占用，用来比"这周比上周多还是少"。
- **规划合理性**：完成率、按期完成、逾期率，加上**领域覆盖缺口**（哪些领域被你冷落了）。
- **休息**：休息时长、工作与休息的比例、作息规律性（开始与结束时间的波动范围）。
- **每张卡片可自选图表类型**：饼图 / 柱状图 / 条形图 / 折线图，按卡片分别记住。
- **保留的仍是完整的**：专注计时、补录、导出、按标签筛选都还在，位置没动。

### 二、日程视图

- **七日日历加上"昨天"**：列头依次是 **昨天 / 今天 / 明天**，再往后是周几；今天那一列用主色描边，
  八列里一眼能找到。订阅范围也跟着往前一天，否则昨天那列会永远空着。
- **已完成的事保留真实样子**：任务勾选完成后，卡片仍显示原标题与领域色，并打上已完成标记；
  固定日程按时间过去同样标记。
- **卡片配色重做**：三个日程页面改用共享的深色填充与低亮描边，并按"色相 + 限饱和度 + 求解明度"
  派生，深得有彩度、不再发灰；四档玻璃材质都跟着适配。
- **「领域与项目」卡片之间补了行间隔**。

### 三、新增：新手教程

七步走一遍主要功能，**每一步配一张真实界面截图**（不是示意图）：

欢迎 → 今日安排 → 任务清单 → 七日日历 → 领域与项目 → 统计与复盘 → 设置与数据安全。

第一次打开会自动出现，可以前后翻、也可以跳过；之后随时从 **设置 → 新手教程** 重看。

### 四、这一版修掉的问题

| 问题 | 说明 |
| --- | --- |
| **重排一次、历史全没** | 原来看的只是"最新一版计划"，而重新生成计划会新建版本——过去几天当时排了什么只留在旧版本里。现在改成：**每个本地日只由一版决定**（当天有当前安排就用当前版；那天已完整过去且当前版没排，就用"当天结束时在用的那一版"还原）。已经发生的事不再被后来的调整改写。 |
| **已完成待办重复** | 上面那个修复的第一版把各版本的块**求并集**了，于是同一件事会出现 2~4 次（例如今天 10:00 与旧版 07:30 各来一次）。已改为按本地日取**单一版本**。 |
| **选择统计范围的日历区不透光了** | 第一版修按钮对比度时把底色写成了不透明，遮住了原来的玻璃透光。现在只改对比度、不改透光。 |
| **选择器右上角按钮几乎看不见** | 两个原因叠在一起：全局按钮主题用的是次要灰，以及应用从未配置中文本地化（那个按钮其实是英文的 `Save`，月份是 `October 2026`）。两处都修了，全库 9 个日期／时间选择器一起生效。 |

### 五、装与升级

- **推荐**：解压整个文件夹 → **双击 `安装.cmd`** → 弹一次 UAC 选"是"。它会自动信任签名证书、
  安装或原位升级，然后报告结果。升级时重复同样操作即可，证书不会重复导入。
- **便携版**：解压后直接双击 `personal_planner.exe`，不需要证书也不需要管理员
  （可能弹一次 SmartScreen，点"更多信息 → 仍要运行"）。
- 数据存在系统的"文档"文件夹里（`personal_planner.sqlite`）。**升级不会动它**；
  便携版的数据在该文件夹内的 `user-data` 子目录。

### 六、已知限制（如实写明）

1. 安装包用的是**自签名证书**，所以别人第一次装必须先用 `安装.cmd` 信任它（这就是那个脚本的作用）。
   要做到"双击即装"，需要购买正式的代码签名证书。
2. 本版本目前是**开发构建／待验收**，尚未登记为正式发布。
3. 教程里的截图是"照当时界面拍的"。界面再改，截图就会过时——所以每次改动都会连同步骤一起复核。
