# 优计主义 1.8.0 更新

## 品牌名称

- 软件正式更名为**「优计主义」**，窗口标题、开始菜单、托盘、通知、备份文件选择器、新手教程和使用文档已统一使用新名称
- 英文项目名继续使用 **Best-Planning**
- 包身份、数据库和可执行文件名保持不变，现有用户可以直接升级，原有数据无需迁移

## 延后与局部调整

- 今日页延后一块计划时，现在**只移动选中的那一块**，不会再把同一任务的其他块一起推后
- 延后会先在**当天**寻找新位置，当天确实放不下时才考虑后续日期
- 固定日程、保护时间、睡眠、锁定块和已经开始的安排都会参与避让，不会再把候选时间放进硬冲突里
- 没有参与本次调整的计划块会留在原位，系统优先选择**改动块数最少**的方案
- 同一块换了时间，预览现在显示为**「移动」**，不再拆成一次删除和一次新增
- 如果无法满足延后要求，会明确提示**「无法按要求延后，当前计划未更改」**，不会把原位置冒充成调整成功

## 计划预览与应用

- 计划预览现在分成三种状态：完整方案可以直接应用；有缺口时显示**「应用可安排部分」**并再次确认；有阻断问题时按钮不可用，并给出重新生成计划的入口
- 在预览页停留期间改过任务时长、规划规则或排程粒度，旧预览会立即失效，避免用旧方案覆盖新输入
- **「信任自动调整」只会自动应用完整方案**；部分计划和含冲突的方案仍会回到预览页，由你确认
- 过去的计划块会继续留在历史日历里，但不再混进新的排程提案，也不会重复出现在变更列表中
- 预览里的任务统一显示**任务名称**，不再出现 UUID；同一个缺口只说一次
- 警告与阻断问题分开显示，真正的排程异常无法通过「应用可安排部分」绕过去

## 排不下时给出具体原因

- 长任务最后一个不足最小片段的**短尾**现在可以排进去。例如 100 分钟、片段范围 30–90 分钟的任务可以排成 `30 + 30 + 30 + 10`
- 12 分钟任务在 5 分钟粒度下会先安排 10 分钟，再明确显示**还缺 2 分钟**，不再整项判定为无法安排
- 未安排原因会写清楚**需要多少、可以安排多少、还缺多少**，并区分连续时间不足、达到每日上限、尚未到最早开始时间等情况
- 修复「日历上明明看得到空闲，却报告容量不足」：按日预算只分配到任务真正可以使用的日期，未来周期实例不会再占用当前规划的容量
- 候选生成、最终校验和实际写入现在使用同一套片段与粒度规则，不会再出现引擎排得出、确认时又拒绝的情况

## 课程与保护时间

- 新增完整的**课程管理与编辑**：可修改课程名称、教师、地点、领域、项目，以及每一段课程的星期、时间和单双周规则
- 保存整门课程前会先显示影响预览，包括新增、修改、删除的课程段数和可能受影响的单次调整；确认后才一次性写入
- 一门课包含「周一单周、周四双周」这类多个片段时，每段会保留自己的星期与周次，不会再因为编辑而被压到同一天
- 同名但不同班的课程改为按**课程 ID**区分，修改一个班不会影响另一个班
- 保护时间管理改为**一条规则一行**，不再把未来 180 天的每次发生都列成一条；可以编辑整个系列，也可以在日历中选择仅本次、此次及以后或整个系列
- 新增**早餐保护**。老用户升级后默认关闭，不会突然改变现有计划；首次引导中默认开启
- 早餐、午餐、晚餐、睡眠等保护窗口发生重叠时，保存前会指出具体重叠区间，不再静默合并

## 日历与桌面体验

- 应用计划、撤销、编辑固定日程、修改课程、修改保护规则、调整领域或配色后，今日页、周视图和日历会立即刷新
- 原「七日日历」更名为**「近期日历」**：范围仍是昨天、今天和未来六天，共八列，标题与实际范围一致
- 日视图中的课程、任务、自定义保护时间和规则保护时间统一操作区宽度，卡片右边界对齐，只显示当前真正可用的操作
- 早餐在近期日历、日视图和今日页都会显示为**「早餐」**；固定日程不再被标成「已完成」
- 修复周时间轴在不同时区下的日期与时间换算，整页统一使用同一个本地时间来源
- 托盘图标现在可以左键恢复主窗口；新建入口会打开对应模块，日期和时间输入改为中文选择器
- 通知总开关、任务提醒和固定日程提醒关闭后，会同步取消已经排队的对应通知；重新开启后按当前计划恢复

## 数据与兼容性

- 数据库从 schema v8 升到 v9，用于区分固定日程与保护时间；从 1.7.1 及更早版本升级会自动迁移
- 升级会保留任务、计划、课程、设置和历史记录，包身份仍是 `ShuoZhuang.PersonalPlanner`
- 最终安装包为 `1.8.0+44`，MSIX 版本 `1.8.0.2`，包含此前候选之后完成的日历、预览与短尾排程修复
- 卸载不会删除用户数据库；升级前仍建议从**设置 → 数据与帮助 → 数据备份与恢复**保存一份备份

安装：解压后**双击「安装.cmd」**即可（弹一次 UAC）。也可以直接用便携版，双击 `personal_planner.exe`。
