# 智能日程 1.4.2+25（开发构建／待验收）

本版是**视觉修复**版：把卡片表面的亮度整体压下来，并保留上一版刚修好的两处装饰件。没有新增
功能，也没有改动数据结构。同时提供 MSIX 安装包和便携版；日常体验建议安装 MSIX，便携版用于安装
失败时排查或临时运行。

## 安装或升级

1. 如果“智能日程”正在运行，请先退出程序；必要时在任务栏托盘图标菜单中选择退出。
2. 双击 `PersonalPlanner-1.4.2-build25-windows-x64-20261006.msix`。
3. 选择“安装”或“更新”。本版 MSIX 版本为 `1.4.2.3`，可以**原位覆盖**本机已有的 `1.4.2.2`、
   `1.4.2.1`、`1.4.2.0` 或 `1.4.1.0`（不需要先卸载，现有任务、领域颜色、课表和设置都会保留）。
4. 安装完成后，从开始菜单启动“智能日程”。

如果 Windows 提示证书不受信任，请先安装同目录的 `PersonalPlanner-signing-cert.cer`：

1. 双击证书，选择“安装证书”。
2. 选择“当前用户”。
3. 选择“将所有的证书都放入下列存储”，将证书放入“受信任人”。
4. 完成证书导入后，再双击 MSIX 安装包。

证书主题应为 `CN=Shuo Zhuang, O=Personal User, C=CN`，指纹应为
`9E157ECE535D16A224593CA39C084705A4FD3C13`。只有核对一致后才应该信任。

> **版本只能往上走**：Windows 不接受比已安装版本更低的安装包。一旦装过 `1.4.2.3`，就回不到
> `1.4.2.2` 及更早的号。

## 便携版

保留本目录内全部运行文件，然后双击 `personal_planner.exe`。不要只把 EXE 单独复制出去；它依赖同目录
的 DLL 和 `data` 文件夹。便携版会在运行目录建立自己的 `user-data`，与安装版的使用场景分开。

## 本次变化：卡片整体调暗

上一版把卡片底色与描边的派生比例定在 `18%` / `32%`，实测偏亮——尤其青蓝、青绿、琥珀那几张，
卡片底色亮度到 `0.0447`，比旧版（`0.034` 左右）亮约三成。本版把两个比例改为 `12%` / `16%`：

| | 卡片底色亮度 | 描边亮度 |
| --- | --- | --- |
| 上一版（`18%` / `32%`） | 0.0325 ~ **0.0447** | 0.0850 ~ 0.1239 |
| 本版（`12%` / `16%`） | 0.0254 ~ 0.0326 | 0.0610 ~ 0.0771 |
| 旧版实测参照 | 0.0338 ~ 0.0343 | 0.0420 ~ 0.0907 |

也就是说：**八种分类的卡片底色现在全部比旧版更暗**，描边也回到旧版的区间内。分类身份仍由左侧
彩色竖条、图标与图例承担，与旧版一致。

上一版修好的两处保持有效：今日卡片左侧的彩色竖条、以及有安排时的今日容量条。
