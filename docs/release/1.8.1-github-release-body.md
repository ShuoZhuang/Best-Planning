# 优计主义 1.8.1 更新

## 排程算法重做

这一版重做了排程内核：不再只盯着"把任务切碎硬塞进空档"，而是先算清每一天到底还剩多少可用时间，再把工作量摊到最合适的几天上

- 周末的空闲终于会被用上。以前它会沿用周一的每日上限，于是继续把工作量堆在工作日，周末一直空着
- 一天里已经锁定的安排会真正占掉额度。以前锁定 300 分钟、上限 360 分钟的一天，还能再排进 360 分钟
- 一个任务被切成几段时会分散到多天，而不是全挤在第一天
- 修复了"每天都不够放一块"的缺陷：180 分钟曾被摊到 8 天、每天 20 到 25 分钟，而最小片段是 30 分钟，于是一个块都排不出来
- 目标改成逐层比较：先看硬约束，再看新增缺口、优先级分布、单日负载率、节奏偏差、稳定性，不再揉成一个加权分数

## 每日上限按当天算

- 每天的每日上限、排程粒度、休息间隔和生活配额，现在各按当天的规则生效
- 以前整周都取窗口第一天那份，于是"周末上限更高"这类设置整周不起作用
- 时段偏好与精力区间本来就分工作日和周末，现在其余的日期敏感字段也一并对齐

## 已有计划会被保留

- 未锁定的既有计划块会带着原来的身份进入重排，因此"尽量少改动"这一步第一次真的生效；修好之前它会重新给所有块起名，找不到任何原来的位置，那一步实际是空操作
- 移动一块会保留它的身份，预览里如实显示为**「移动」**，不再拆成一次删除加一次新增
- 锁定块、固定日程、保护时间的身份与语义没有改动
- 局部改进新增方案级把关：某一块换到更讨喜的位置时，还会再比较整份方案是否更好，否则不动。这挡住了实测出现过的一种坏形状——局部精力分更高，却把工作日负载从 70% 推到 100%、周末仍是 20%
- 局部改进现在也守住跨日预算，不会把分配好的额度在收尾阶段挪乱

## 排不下时的原因更诚实

- 高精力任务被排到普通时段时，以前给出的理由是**「优先级较高」**，那与实际原因无关，你也没法据此做什么
- 现在会如实说**「偏离精力偏好」**，你因此知道可以调整精力区间，或者把占住那个时段的课挪开
- 旧计划里的旧解释仍能正确显示，不会退化成笼统的「排程调整」

## 数据与兼容性

- 数据库 schema 没有变化，从 1.8.0 及更早版本升级**不需要迁移**
- 升级会保留任务、计划、课程、设置和历史记录，包身份仍是 ShuoZhuang.PersonalPlanner
- 最终安装包为 1.8.1+45，MSIX 版本 1.8.1.0
- 已装 1.8.0.x 的用户可以直接覆盖升级；安装前请先退出正在运行的应用
- 卸载不会删除用户数据库；升级前仍建议从设置 → 数据与帮助 → 数据备份与恢复保存一份备份

## 已知限制

- 不承诺数学意义上的全局最优
- 精力与期望时段仍然只是软偏好：排不下时会偏离，但会如实说明
- 任务依赖关系与通用通勤时间不在本次范围内

安装：解压后**双击「安装.cmd」**即可（弹一次 UAC）。也可以直接用便携版，双击 personal_planner.exe。
