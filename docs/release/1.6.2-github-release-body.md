# 智能日程 `1.6.2`（`1.6` 发布线的正式版本）

> **这是 `1.6` 发布线的唯一一个正式版本**，把九个内部里程碑（M1～M9）合并交付。
> 里程碑本身不单独发布、不单独占版本号。

任务怎么排、今天是哪几件事、时间花在哪、设置在哪改——这四件事此前各自能用但**接不起来**。
这一版把它们接成一条闭环，并修掉若干"**不报错但结果不对**"的缺陷。

---

## 三个最值得单独说的改动

### 1. 「跳过本次」不是「延后到明天」

今天这一块做不了时，此前的选择只有"延后到明天"——而明天未必合适。现在**三个动作是分开的**：

| 动作 | 含义 |
| --- | --- |
| **跳过本次** | 只丢掉**今天这一块**；任务仍是待办，剩余时间不变（只扣真实专注过的部分），系统**重新找一个合适的空档** |
| **延后到明天** | 明确把可用时间推到明天 |
| **取消任务** | 任务本身作废 |

重找时间时**默认先给你看调整预览**，只有你开了「信任自动调整」才直接应用。
实在排不下时会明说"待安排／有逾期风险"以及差多少，**而不是硬塞**。

### 2. 七日日历多了一个「时间轴」模式

按**真实时间比例**排列：一小时就是一小时那么高。同时进行的事**并排**显示，不会一个盖住另一个。

> 隐藏在这条下面的技术点：像 `9:00–11:00`、`9:30–10:00`、`10:30–11:30` 这种**交叉重叠**（首尾两块也重叠）必须排成**三列**，而"找个空位放下"的常见写法会给两列、然后两块左右压在一起。这里是按**团**算的，所以画面不会骗你。

紧凑模式**完全保留**，选择会被记住。

### 3. 首次引导从"看一遍"变成"做一遍"

确认完默认值之后，引导**不再就此结束**，而是给你三个真实入口：

```
[创建第一个任务]     ← 已经用过的话，这里写「再创建一个任务」
[导入课表]
[了解主要界面]
```

**在引导里建的任务就是普通任务**——同一张表、同一套默认值与校验，能编辑、能删除、能完成、
能拆分、能重排，统计和日历里照常显示，**没有任何隐藏标签或特殊类型**。

**四种退出方式是四件不同的事**：

| 你的操作 | 结果 |
| --- | --- |
| 中途退出（返回／关窗口／崩溃） | **不算完成**。下次启动会问：`上次的新手引导还没有完成` |
| 暂时跳过 | 只跳过**这一次**，下次启动还会问 |
| 跳过引导 | 以后不再自动弹 |
| 完成 | 不再自动弹 |

**「重新开始」只重置引导进度**，已建的任务、导入的课表、已确认的计划**一个都不删**。
设置里也新增了「**首次引导**」入口，随时能重看。

## 全部改动

**任务与分类**
- 任务清单新增「**全部／待安排／已安排／已完成**」筛选，带数量、可用键盘切换、窄窗可横向滚动
- 每张卡片显示**真实状态**：`待安排 · 预计 50 分钟` / `已安排 · 13:00–14:30` / `已完成 · 实际投入 25 分钟`，逾期再加「已逾期 · 截止于…」
- 任务页改为读取**全部**任务（此前只读未结束的，因此"已完成"永远是空的）
- 新建任务页：更清楚的分区，「更多选项」默认收起；**保存失败/缺字段会明确指出来**，而不是静默留在原页
- 日期与时间选择器中文化，选中日与"今天"的对比度修好

**今日执行与重排**
- 「跳过本次」按上面第 1 点实现，三个动作互相独立
- 计划预览把变更分成 **新增／移动／拆分／未安排／保护时间变化**，并给出原时间与目标时间

**周日历**
- 新增「紧凑／时间轴」切换，默认**紧凑**（不强迫你接受新密度），选择会记住
- 时间轴按真实比例绘制，重叠**并排**，显示真实起止时间，长标题省略并可悬停看全
- 150% 缩放下仍可操作

**课表导入**
- 图片读不出来时说清**是哪张**（文件名，不含目录路径）、**支持哪些格式**（PNG/JPG/JPEG），并在失败处**就地**给「更换图片」
- 再也不会看到 `PathAccessException`、`OS Error 5` 这类系统文本
- 周数与第一周日期的双向换算补齐**跨年、学期中途、非法日期**测试

**统计与复盘**
- 同一领域在今日、日历、统计三个页面显示**同一个颜色**（此前统计页自己按"排在第几个"取色，因此对不上）
- 图表四档材质下通过对比度检查（文字 ≥ 4.5:1、图形 ≥ 3:1），饼图改为**下方图例**——原先切片上的白字最浅只有 **1.85:1**，换深色也有两种颜色不达标
- 自定义日期范围的边界补齐测试：**末日含当天**、单日、跨月、跨年、12/31、闰年 2/29

**设置**
- 首页按**规划与时间／外观与交互／通知与隐私／数据与帮助**四组分区
- 每个入口右侧显示**当前值**（例如"默认专注 50 分钟"、"材质：克制"）
- **修掉一个会丢改动的真问题**：规划规则页有二十多个输入框，改动只在点「保存设置」时才落库，而此前**返回、点侧栏、关窗口都会静默丢掉**。现在离开时会先问一句，默认那一侧是**继续编辑**；没改过东西时不弹框

**数据安全**
- **修掉一处会泄漏本机路径的缺陷**：备份失败时兜底分支原先把异常原样打印，而 Dart 的文件异常 `toString()` **带着完整路径**。现在会替换成人话，同时**保留"拒绝访问""网络名不再可用"这类有用信息**

**收口前两处实测反馈**
- **今天做完的事在今日和日历界面消失**：勾选完成会触发重排，而已完成的任务不再参与排程，于是新版本计划里没有它的时间块；视图那条"当天只看当前版"的规则让今天正好命中。现在会补上**已结束任务在过去时间里的块**——今天做完的事仍然显示在做它的时间，带完成标记
- **统计页「自定义范围」常亮**：那个按钮写死成实心，所以不管你选哪个范围，亮着的都是它。现在**选哪个哪个亮**

## 已知限度（如实说明）

- **时间轴模式里不能拖动。** 拖动移动仍只在「紧凑」模式可用——"拖到几点"与"拖到哪一天"不是同一套语义，我没有随手发明它
- **时间轴只画你有安排的时间范围**（例如 9:00–21:00），不能滚动到整天完全没有安排的时段
- **引导的三个入口复用既有页面**，不是引导专用的简化流程。这是刻意的：引导里建的任务必须与你平时建的任务完全一样，所以走同一条路

## 安装

**方式一（推荐）**：下载下面的 `.zip`，**完整解压**后双击 **`安装.cmd`**（会弹一次 UAC）。

**方式二（便携）**：解压后直接双击 `personal_planner.exe`，无需安装。

> 本包用**自签名证书**，因此 `安装.cmd` 会先用一次管理员权限把公钥证书（`.cer`）装进
> 「本地计算机 → 受信任人」，再安装或**原位升级** MSIX。
> **卸载不会删除你的数据** —— 数据库不在安装目录里。

要求：Windows 10/11 x64。包内自带全部运行时，**不需要** Flutter 或任何开发环境。
