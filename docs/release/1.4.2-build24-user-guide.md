# 智能日程 1.4.2+24（开发构建／待验收）

本版是**视觉修复**版：把今日页两处「存在但画不出来」的装饰件修好，没有新增功能，也没有改动数据
结构。同时提供 MSIX 安装包和便携版；日常体验建议安装 MSIX，便携版用于安装失败时排查或临时运行。

## 安装或升级

1. 如果“智能日程”正在运行，请先退出程序；必要时在任务栏托盘图标菜单中选择退出。
2. 双击 `PersonalPlanner-1.4.2-build24-windows-x64-20261006.msix`。
3. 选择“安装”或“更新”。本版 MSIX 版本为 `1.4.2.2`，可以**原位覆盖**本机已有的 `1.4.2.1`、
   `1.4.2.0` 或 `1.4.1.0`（不需要先卸载，现有任务、领域颜色、课表和设置都会保留）。
4. 安装完成后，从开始菜单启动“智能日程”。

如果 Windows 提示证书不受信任，请先安装同目录的 `PersonalPlanner-signing-cert.cer`：

1. 双击证书，选择“安装证书”。
2. 选择“当前用户”。
3. 选择“将所有的证书都放入下列存储”，将证书放入“受信任人”。
4. 完成证书导入后，再双击 MSIX 安装包。

证书主题应为 `CN=Shuo Zhuang, O=Personal User, C=CN`，指纹应为
`9E157ECE535D16A224593CA39C084705A4FD3C13`。只有核对一致后才应该信任。

> **版本只能往上走**：Windows 不接受比已安装版本更低的安装包。一旦装过 `1.4.2.2`，就回不到
> `1.4.2.1` 及更早的号。

## 便携版

保留本目录内全部运行文件，然后双击 `personal_planner.exe`。不要只把 EXE 单独复制出去；它依赖同目录
的 DLL 和 `data` 文件夹。便携版会在运行目录建立自己的 `user-data`，与安装版的使用场景分开。

## 本次变化

- **今日卡片左侧的彩色竖条回来了**。它一直存在于代码里，但行的对齐方式让它被量成 0 高度，
  所以屏幕上完全看不到——这也是为什么此前今日页的卡片看起来是“整块变色”，而不像旧版那样
  “中性深底 + 左侧一条分类色”。现在竖条会铺满卡片高度。
- **今日容量条在有安排时能看见了**。同一个成因：各段（按分类占比切分）高度为 0，于是“有安排时
  容量条消失”，反而“当天没有安排”那条灰色底条一直可见。
- 两处都已加上会失败的回归断言（只断言颜色是不够的，必须断言**尺寸**），以后同类写法会在测试里红。
- 卡片配色与上一版候选（`1.4.2+23` / MSIX `1.4.2.1`）**完全相同**，未做调整。
