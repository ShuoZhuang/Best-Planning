# 优计主义 1.10.0 更新

1.10.0 把新用户的安装方式改成一个文件：双击、同意一次管理员授权即可完成，断网也能装。
同时修复了两个会阻断升级的问题：更新包落盘失败，以及应用内升级时助手占用安装包。

## 新用户：一个文件，断网也能装

- 下载 `BestPlanning_Setup_1.10.0_x64.exe`，双击运行
- 整个过程只请求一次管理员权限，用来把发布证书放进「本地计算机 → 受信任人」
- 安装器内含完整 MSIX 与公开证书，**不联网也能完成首次安装**
- 不需要 PowerShell、批处理、证书管理器，也不需要单独下载 `.msix`
- 装完自动启动；已经安装同等或更高版本时不会重复安装

## 从 1.9.x 升级：这一次请手动安装

- `1.9.x`（包括 `1.9.2`）的应用内更新存在缺陷：更新助手从安装包内部启动，自己占住包文件，
  Windows 会以“包正在使用”（`0x80073D02`）拒绝安装，因此 `1.9.x` 无法自动升级到任何新版本
- `1.10.0` 已修复：启动更新助手前，先把它复制到安装包之外的临时目录，再执行部署
- 从 `1.10.0` 开始，后续版本可以正常应用内更新
- 已经安装 `1.9.x` 的用户，请下载 `BestPlanning_Setup_1.10.0_x64.exe` 手动安装一次；
  任务、计划和设置都会保留

## 更新仍然逐项验证

- 主程序和更新助手都会核对安装包大小、SHA-256、数字签名、发布者、包身份、架构和版本
- 更新助手只接受更新目录中已经完成下载的 `.ready` 文件，不执行脚本，也不接受其他路径的程序
- 更新缓存改用 Windows 包身份提供的 `LocalCacheFolder`，下载完成后才能完成落盘
- 下载中断或落盘失败时保留可恢复的 `.partial`；重启后先重试验证与提升，不会重新下载

## 数据与兼容性

- 应用版本为 `1.10.0+49`，MSIX 版本为 `1.10.0.0`
- 包身份和数据库结构与 `1.9.x` 相同，不需要数据迁移
- 任务、计划、课程、设置、偏好和历史记录都会保留
- 已经安装 `1.9.x` 的用户可以直接覆盖安装；升级前建议先保存一份数据备份

## 已知限制

- `1.9.x` 无法应用内升级到 `1.10.0`，必须手动安装一次（`1.10.0` 起已修复）
- 同版本的「修复安装」只重新登记应用，不会替换已安装文件；文件损坏需要先卸载再安装
- 便携版没有 Windows 包身份，不参与自动更新，也不会注册通知
- Microsoft Store、差分补丁和其他桌面系统不在本次范围内

安装：下载 `BestPlanning_Setup_1.10.0_x64.exe`，双击后按提示完成安装。
