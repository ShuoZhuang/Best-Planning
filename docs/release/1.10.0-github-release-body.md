# 优计主义 1.10.0 更新

1.10.0 把“新用户第一次安装”变成一个文件、一次授权。已经装过旧版本的用户不需要重新下载：
应用内的自动更新会继续用 MSIX 完成升级。

## 升级前请先更新到 1.9.2

自动回退由“当前已安装版本”内置的更新助手执行。`1.9.0` / `1.9.1` 内置的旧助手在回退时
不支持降级部署，所以如果从它们直接升级到 `1.10.0` 后健康确认失败，无法自动回退。

**已经安装 1.9.0 / 1.9.1 的用户，请先更新到 `1.9.2`（只修助手，没有业务变化），再升级
`1.10.0`。** 从 `1.9.2` 升到 `1.10.0` 的一跳已实测可自动回退（失败时回到 1.9.2 并重新启动）。
用 Setup 安装/升级的用户不受此限制影响。

## 新用户：一个文件，断网也能装

- 下载 `BestPlanning_Setup_1.10.0_x64.exe`，双击运行
- 整个过程只请求一次管理员权限，用来把发布证书放进“本地计算机 → 受信任人”
- 安装器内含完整 MSIX 与公开证书，**不联网也能完成首次安装**
- 不需要 PowerShell、批处理、证书管理器，也不需要单独下载 `.msix`
- 装完自动启动；应用已经装过同等或更高版本时不会重复安装

## 安装前先把关

- 依次核对载荷长度、SHA-256、清单里的包身份/发布者/架构/版本
- 验证 MSIX 数字签名的密码学完整性，并要求实际签名者正是安装器内置的那张证书
- 只有以上全部通过，才会导入证书；导入之后再按 Windows 正常的证书链规则复验一遍
- 证书只写入“受信任人”，不写入“受信任的根证书颁发机构”，也不导入私钥

## 权限没有被放大

- 安装器自身不以管理员身份常驻：它只在“信任证书”这一步发起一次提权
- 标准账户在 UAC 中输入管理员凭据时，MSIX 仍然安装给**发起安装的那个用户**，不会装给管理员账户
- 提权进程只做一件事：从安装器自身的只读资源里重读证书与载荷、再校验一次、写一次证书，然后退出

## 升级与修复

- 已安装较低版本：原位升级，不卸载、不清除数据
- 已安装相同版本：可以选择“启动应用”或“重新安装”（重新安装不会先卸载）
- 已安装更高版本：拒绝降级，并给出明确提示
- 身份或发布者冲突：停止并提示，不自动替换

## 数据与兼容性

- 应用版本为 `1.10.0+49`，MSIX 版本为 `1.10.0.0`
- 包身份 `ShuoZhuang.PersonalPlanner`、发布者与数据库结构都没变，不需要数据迁移
- 任务、课程、保护时间、学习偏好和历史记录都会保留
- 应用内更新的行为没有改变：后台下载、左下角入口、点击后才安装

## 已知限制

- 安装器只支持 Windows 10 1809 及以上、Windows 11 的 x64 版本
- 自签名证书阶段仍可能出现 SmartScreen 提示；请核对来源后选择“更多信息 → 仍要运行”，
  安装器不会修改系统安全策略来绕过它
- 便携版没有 Windows 包身份，因此不参与自动更新，也不会注册通知
- 在阻止部署的待重启状态下，安装器会提示先重启（普通的临时文件待重命名不会被当成阻塞）
- **从 `1.9.0` / `1.9.1` 应用内直接升级的用户，如果新版健康确认失败，不会自动回退**：回退由已安装
  版本内置的更新助手执行，而 `1.9.0` / `1.9.1` 内置的助手不支持降级部署（先升到 `1.9.2` 即可解决）；`1.10.0` 起已修复，之后的
  升级可以正常回退。如果新版无法启动，请按“手动恢复”卸载 `1.10.0` 后安装 `1.9.0`；
  任务与设置保存在文档目录，不会因卸载而删除
- 同版本的“修复安装”只重新登记应用，**不会替换已安装文件**；文件损坏需要先卸载再安装

## 遇到问题时

- 安装失败会显示简明原因、当前系统状态、处理建议和一个稳定错误编号
- 可以点“打开日志”查看 `%LOCALAPPDATA%\BestPlanning\Setup\setup-*.log`；日志不含任何任务或课程内容
- 需要人工部署或排查时，可以继续使用同一次 Release 里的 `.msix`、`update-manifest.json` 与 `SHA256SUMS.txt`

安装：下载 `BestPlanning_Setup_1.10.0_x64.exe`，双击即可。
