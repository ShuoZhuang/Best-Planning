# 智能日程 1.4.2+26（开发构建／待验收）

本版是**视觉修复**版：换了卡片底色的**派生方式**，让卡片既深又有彩度——与旧版（1.0.11）卡片
的性格对齐。没有新增功能，也没有改动数据结构。

## 安装或升级

1. 如果“智能日程”正在运行，请先退出程序；必要时在任务栏托盘图标菜单中选择退出。
2. 双击 `PersonalPlanner-1.4.2-build26-windows-x64-20261006.msix`。
3. 选择“安装”或“更新”。本版 MSIX 版本为 `1.4.2.4`，可以**原位覆盖**本机已有的 `1.4.2.3`
   及更早的 `1.4.2.x` / `1.4.1.0`（不需要先卸载，现有任务、领域颜色、课表和设置都会保留）。
4. 安装完成后，从开始菜单启动“智能日程”。

如果 Windows 提示证书不受信任，请先安装同目录的 `PersonalPlanner-signing-cert.cer`：

1. 双击证书，选择“安装证书”。
2. 选择“当前用户”。
3. 选择“将所有的证书都放入下列存储”，将证书放入“受信任人”。
4. 完成证书导入后，再双击 MSIX 安装包。

证书主题应为 `CN=Shuo Zhuang, O=Personal User, C=CN`，指纹应为
`9E157ECE535D16A224593CA39C084705A4FD3C13`。只有核对一致后才应该信任。

> **版本只能往上走**：Windows 不接受比已安装版本更低的安装包。一旦装过 `1.4.2.4`，就回不到
`1.4.2.3` 及更早的号。

## 便携版

保留本目录内全部运行文件，然后双击 `personal_planner.exe`。不要只把 EXE 单独复制出去；它依赖同目录
的 DLL 和 `data` 文件夹。便携版会在运行目录建立自己的 `user-data`，与安装版的使用场景分开。

## 本次变化：卡片改成「深 + 有彩度」

此前几版一直在调“往深色表面混多少”，结果越调越灰：

| | 琥珀色卡片底色 | 彩度（HSV 饱和度） |
| --- | --- | --- |
| 早期（混 26%） | `#4e473c` | 23% |
| 上一版（混 12%） | `#2f3336` | **13%** —— 几乎是中性灰 |
| **本版** | `#463011` | **83%** |
| 旧版（1.0.11）保护时间 | `#49371f` | 58% |

原因是“混色”把两件事绑死了：**越往深处混，彩度掉得越干净**。所以本版把两件事分开：

- **色相与彩度**取自分类色（彩度上限 60%，本来就灰的颜色不会被硬拉成彩色）；
- **明度**由目标亮度解出来，八种分类的卡片**重量一致**（实测亮度 `0.0335 ~ 0.0348`，1.04 倍；
  旧版是 `0.0318 ~ 0.0428`）。

结果：卡片比旧版**不亮**（逐色不超过旧版最亮的一张），但**有彩度**，不再是被提亮的灰。
描边用同一规则、目标亮度更低，落在旧版描边的区间内。

上一版修好的两处保持有效：今日卡片左侧的彩色竖条、以及有安排时的今日容量条。
