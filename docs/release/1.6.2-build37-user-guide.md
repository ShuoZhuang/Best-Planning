## 1. 任务状态可信（M1）

### 你能做什么

任务页现在按状态分四栏，顶上就是筛选栏：

```text
[ 全部 8 ] [ 待安排 2 ] [ 已安排 4 ] [ 已完成 2 ]
```

- **全部**：你能看到的全部任务（＝ 待安排 ＋ 已安排 ＋ 已完成）。
- **待安排**：还没进入当前计划的任务。刚建好还没生成计划、原来安排的时间已经过去、
  或者逾期之后还没有补排，都在这里。
- **已安排**：**当前计划里还有一段没结束的时间**的任务。正在进行的、逾期但已补排到未来的、
  被拆成几段且至少一段还没结束的，都算。
- **已完成**：做完的任务。它们会一直留着，随时可以取消勾选把它改回"待安排"。

数量跟着数据实时变，而且**搜索不会改变这些数字**——搜完只剩一条时，筛选栏仍然显示全量，
让你知道自己是站在多大的一堆里搜。

### 每张卡片都会说清自己的状态

```text
算法作业
待安排 · 预计 50 分钟

大物预习课
已安排 · 13:00–14:30

竞赛报名
已完成 · 实际投入 25 分钟

大物作业
已逾期 · 待安排 · 截止于 10月6日 23:59
```

几条口径：

- **"已逾期"是提醒，不是第四种类别**。逾期但已补排到未来的任务会显示
  `已逾期 · 已安排 · 21:00–22:00`——它确实逾期过，而现在的安排是有效的。
- **已经过去的时间段不算"已安排"**。昨天排的计划不会让今天还显示"已安排"，它会回到「待安排」。
- **已完成优先于已安排**：一个任务勾选完成后，**即使计划里还留着它的时间块**，它也在
  「已完成」里，不会同时出现在两栏。
- **卡片颜色仍然是领域色**，不因为状态换色——颜色表示"这件事属于哪个领域"，状态用文字说。

### 空列表会说清为什么空

| 你看到的 | 意思 |
| --- | --- |
| 还没有任务 | 一条任务都还没有，旁边有"新建任务" |
| 没有待安排任务 | 进行中的任务都已经进入计划了 |
| 没有已安排任务 | 当前计划里没有任务，旁边有"生成计划" |
| 还没有已完成任务 | 还没有做完过任何事 |
| 没有找到"×××" | 搜索没命中，旁边有"清除搜索条件" |

### 多选

- 「待安排」「已安排」「全部」都能进多选。
- 「全部」里**已经完成的任务不能勾选**（要改就切到「已完成」）。
- 「已完成」这一栏不显示"多选"按钮。
- **切换筛选会自动退出多选并清空已勾选的任务**——避免你对着看不见的任务执行批量操作。

> 「已取消」和「已跳过」的任务**不会出现在这四个筛选里**，但**数据一条都没有删除**，
> 将来会有一个单独的"归档任务"入口来查看。

### 这一节修掉的是什么

任务页此前只读**未结束**的任务，于是"已完成"永远是空的：你做完一件事之后就再也看不到它，
也无法把误完成的任务改回来——而任务表里那些已完成、已取消的记录一直躺在库里，没有任何界面
能看到。这一节把读取口径换成全部，并把"是否已安排"从任务表里的旧状态改为**按当前确认计划
的未来时间块现算**，因此任务自身的持久化状态没有新增字段。

## 2. 可访问与可读基线（M2）

> **状态：自动化部分已完成并通过（891 项测试）；人工验证（屏幕阅读器实走 + 辅助技术节点检查）
> 尚未完成，因此本章仍可能在 M2 收尾时补充。** 下面写的都是**已经在本机候选里生效**的行为。

### 键盘操作

- **Tab 顺序是稳定、可复现的**：一直按 Tab 能依次走到筛选项、任务卡片上的按钮、批量操作按钮。
  同一页面两次遍历得到完全一样的顺序。
- **Enter 与 Space 都能激活**：焦点的筛选项按 Enter 或 Space 会真的切换筛选（不是"看着像能按"）。
- **Esc 返回上一级**：在子页面（任务详情、设置子页、日历等）按 **Esc** 会回到上一级。
  **顶层页面**（今日／任务／日历／统计／设置）按 Esc **不会**把你弹走。
  > 这是本版新加的：此前返回只能点左上角那个箭头，键盘用户没有对应按键。
- **焦点是可见的**：主题为键盘焦点提供了明确的焦点配色。

### 可读性（对比度）

用 WCAG 公式**实测**（不是肉眼估）并修掉了几处不达标：

| 位置 | 修前 | 修后 |
| --- | --- | --- |
| 卡片副标题那类次要文字 | 4.19（标准 4.5） | 5.54 |
| 主按钮上的白字 | 3.27 | 4.61 |
| 鼠标悬停时的主按钮白字 | 2.47 | 4.63 |

另外补了两处**缺失的控件配色**（此前它们会回落到不适配深色的默认值）：

- 「今天／本周／本月／自定义范围」这些**描边按钮**上的文字——修前只有 **2.17:1**，几乎是淡的；
- **筛选项与图表类型胶囊**的选中态文字——修前选中与未选中都没有专门配色。

四档玻璃材质（无／克制／激进／极致）**都**通过了对比度检查。**没有靠关掉玻璃效果来过关**。

### 屏幕阅读器

- **任务卡片上的"查看详情"有名字了**：会念成「查看「算法作业」详情」，而不是一个没有名字的
  "按钮"。**筛选栏每个选项只念一次**（此前会被念两遍）。
- **错误会被主动播报**：保存失败、新建项目失败、统计加载失败等提示现在都是"实时区域"，
  屏幕阅读器会在它出现时念出来，而不是等你自己逛到那一行。
- **减弱动画生效时**，鼠标跟随的背景高光不再做平滑拖尾（过渡时长压到 0）。

## 3. 新建任务与领域项目闭环（M3）

**状态：界面已改好并验证；人工计时验收待做。**

### 新建任务时，最常用的东西一眼就能看到

打开「新建任务」，不用滚动、也不用展开任何东西，就能看到这七项：

| 字段 | 说明 |
| --- | --- |
| 任务标题 | 要做什么 |
| 预计时长（分钟） | 需要多少时间，默认用你的专注时长 |
| 所属领域 | 长期要负责的方向 |
| 所属项目 | 该领域下有边界的阶段性成果（可选） |
| 最早开始时间 | 硬限制：安排不会早于它 |
| 截止时间 | 可选 |
| 安排方式 | 可拆分／必须连续 |

**优先级、精力要求、每段最短/最长、期望时段、备注**收进了「更多设置」。这些是偶尔才改的，
默认值大多数时候就对；需要时点一下展开即可。

### 保存按钮固定在底部，不会再滚丢

保存按钮从表单末尾移到了**固定底栏**，始终贴在窗口底部。底栏还会同时告诉你两件事：

- **还缺什么**（例如"还缺：标题"）——不用滚到底才知道为什么存不了；
- **当前关键约束**（领域、项目、拆分方式、最早开始、截止）——填之前就能复核一遍。

### 领域和项目会互相照看

- 选好领域，项目下拉里就只出现**属于这个领域**的项目。
- 换了领域、而原来选的项目不属于新领域时，项目会被清空，并且**明确告诉你清空的是哪一个**
  （"原项目「算法课」不属于当前领域，已清空"），不会静默丢掉你的选择。
- 新建项目时可以改归属领域，默认继承任务当前选的领域。
- 领域和项目各配了一句短说明和例子：「领域：长期要负责的方向，例如「学业」」、
  「项目：有边界的阶段性成果，例如「算法课」」。

### 领域页：两个控件改成了说得清的样子

设置里的领域页原先有一个**没有文字的生活开关**和一个**没有文字的颜色圆点**，两者都看不出
是在做什么。现在：

- 生活开关旁边写着**「计入个人生活时间」**，屏幕阅读器也会念出"「学业」：计入个人生活时间"；
- 颜色控件带**「颜色」**标签，屏幕阅读器会念出"更换「学业」领域颜色"。

### 这一节修掉的是什么

- 原来优先级、精力、备注**占着首屏**，而真正常改的领域/项目/时间要往下滚；
- 原来保存按钮是表单的最后一个元素，**滚到中间就看不到它**，在 150% 缩放下更容易发生；
- 原来切换领域会**静默清空**已选项目，用户会以为自己的选择被吞掉了；
- 原来领域页那个生活开关**没有文字**，光和颜色表达状态；
- **选日期时，"今天"被选中后数字会消失**（蓝色字画在蓝色圆上）——见下面一节。

### 自动化证据

`test/features/tasks/task_editor_page_test.dart` 增加 4 条（首屏分层、固定底栏与缺失字段、
领域切换清空说明、100%/150% 缩放下按钮可见）；
`test/app/task_editor_route_test.dart` 新增（在**真实外壳**里挂载并确认底栏还在——
这条挡的是"外壳若改成无界高度，固定底栏会直接炸"的回归）；
`test/features/workspace/workspace_management_page_test.dart` 增加 2 条（生活开关与颜色控件的可读标签）。

### 选日期时"今天"不再消失

日期选择器里，**当天**那一格本来带一个强调色。选中它之后，数字会**用同一个强调色**画在
同一个颜色的圆上——同色，等于空白（对比度 1.0:1）。你看到的"数字不见了"就是这个。

现在选中当天时，数字改用**浅色**写（`textPrimary` 在强调色上是 **4.68:1**，达到 WCAG AA），
所以数字始终看得见。回归测试见 `test/design/date_picker_today_contrast_test.dart`。

## 4. 今日执行与调整信任（M4）

**状态：今日页的执行动作已可用；调整预览的明细分组与「延后／请求调整／跳过」尚未做。**

### 今日页不再只是看板

打开「今日」，**正在进行的那一项**（时间已经落在它里面）会在卡片上直接给你两个按钮：

- **「开始专注」**——一键进入专注计时（进页面算一次、点它算一次，共两次）；
- **「完成」**——直接勾完成，不用先跳去任务详情。

其余各项右侧有一个**「更多操作」菜单**，里面是「查看详情」和「**跳过本次**」。

> 为什么主动作做成按钮、其余收进菜单：如果把"开始专注"也塞进菜单，点起来就变成三次操作了；
> 反过来，每张卡片都堆满按钮，时间线会变成一片按钮墙。

### 「跳过本次」＝这次不做了，但事情还在

点「跳过本次」的意思是：**今天这一格不做，但这件事仍然是你要做的。**

具体发生什么：

- 今天时间线上**这一格消失**，那段时间**空出来**（不是"封起来"，别人可以用）；
- 任务**还在你的待办里**，剩余时长**不变**——你已经专注过的那部分不会被抹掉；
- 智脑**重新给你找一个合适的空档**，会在**截止时间之前**找。
  新时间可能是**今天稍后、明天、或者别的日子**——它不会偷懒一律塞到明天；
- 默认会先给你看**调整预览**（改了什么、从哪到哪）；如果你开了「信任自动调整」，
  它就直接调整好并告诉你；
- 如果实在**排不下**，它会如实说"这个任务还缺 N 分钟"（在预览的「未安排」里），
  不会假装排好了。

**这和另外两件事不是一回事**（菜单里也分开）：

| 你想表达 | 该用哪个 | 现在有吗 |
| --- | --- | --- |
| 今天这一格不做了，事情还留着 | **跳过本次** | ✅ 有 |
| 我**明确**要明天再做 | 延后到明天 | ❌ 还没做 |
| 这件事我**不做了** | 取消任务 | ❌ 还没做 |

> 为什么必须分开：如果把"跳过"做成"顺延到明天"，你就失去了"随便哪天都行、你帮我找"这个选项；
> 而"取消任务"会把任务整个移出待办——那是另一个决定，不该藏在"跳过"里。
> 后两者**目前还没有界面入口**，我没有拿"跳过"去顶替它们。

**哪些条目没有任务动作**：固定日程（上课、开会）与保护时间（吃饭、睡觉）**不给**
「完成／开始专注」——它们的"完成"是**时间过去**，不是你去勾它。所以你在固定日程上看不到
「完成」按钮，这是有意的，不是漏了。

### 重排提示可以关掉

顶部出现「有一份新的安排建议待确认」时，右上角有**关闭**按钮。

**关掉只是不再显示这条提示，不会取消那份待确认的方案**——你随时可以去计划预览页看它。
而且**下次生成的新方案仍然会提醒**（关掉的是"这一条"，不是"以后都别提醒我"）。

### 这一节修掉的是什么

今日页此前**完全没有任何动作**：看到"现在该做这件事"之后，用户得自己想办法跳去别处才能开始。

### 调整预览会说清"改了什么、从哪到哪"

计划有变动时，预览页按**五类**分组列出：

**新增** · **移动** · **拆分** · **未安排** · **保护时间变化**

点开每一条，会看到**原时间**、**目标时间**和**原因**。例如：

```
实验
  原时间　　10-05 09:00–10:00
  目标时间　10-05 14:00–15:00
  匹配高精力时段
```

只有一侧的两类会**只显示那一侧**，不会编一个占位文案：**新增**只有目标时间，
**未安排**只有原时间（它没被排进去）。

> 第四类从原来的「移除」改称**「未安排」**：没排进去的任务**还在你的任务列表里**，
> 只是这一版计划装不下。写成"移除"会让人以为一项待办被删了。

**关掉预览（不点确认）不会改动任何东西**：已确认的计划、锁定的时间块、
任务的原始信息都不会变。只有点「确认应用」才会落地。

## 4.5 今天做完的事，仍然看得见

**这一条是你实测反馈后修的**：你问"我今天完成的算法作业为什么在今日和日历界面不见了"。

**发生了什么**：勾选"完成"会触发一次重新排程，而**已经做完的任务不再参与排程**——
所以新版本的计划里就没有它的时间块了。本来这没问题，但视图里有一条规则是
"当天有当前版的安排就只显示当前版"，于是**今天**正好命中，那条已经做完的记录**整天消失**。

**现在的行为**：当天在当前版的安排之外，会**补上已结束任务在过去时间里的那些块**——
所以你今天做完的事，在今日与日历上仍然显示在做它的那个时间，并带完成标记。

边界收得很紧，为的是不重犯以前那个"同一件事显示两次"的毛病：

- 只补**已经做完／取消／跳过**的任务；
- **当前版已经给它排了位置就不补**（那个旧位置已被取代）；
- 只补**整段时间已经过去**的块（未来的时间不存在"做完了"）。

## 5. 真实时间比例的周日历（M5）

### 同时进行的事会**并排**，不会互相盖住

## 8. 首次引导：从"看一遍"变成"做一遍"（M8）

现在分成四组：

**规划与时间** · **外观与交互** · **通知与隐私** · **数据与帮助**

空的组不会显示（没装的功能不会留一个空标题让你以为"还没加载出来"）。

### 每个入口直接写着"现在是什么样"

以前每个入口只有一句**说明**，比如"在无玻璃、克制、激进和极致液态玻璃之间切换"——
它不告诉你**当前**是哪一档。于是想确认"自动调整到底开没开"，只能点进去一项项翻。

现在每个入口右侧直接写着当前值，例如：

- 规划规则与默认值 → **默认专注 50 分钟**
- 外观与材质 → **材质：克制**
- 应用锁 → **应用锁：关闭**

注意"默认专注"读的是**生效值**（把默认值、你的通用修改、工作日/周末差异、当日例外逐层算完
的结果），不是"你改过没有"——所以它显示的永远是你今天真正会用到的那个数。

### 改了东西没保存就离开，现在会问你一句

这是本轮修掉的一个**真问题**：规划规则页有二十多个输入框，但改动**只在点「保存设置」时**才存下来。
在此之前，你改完之后按返回、点侧边栏、或者直接关窗口，**刚才的改动会无声无息地消失**——
没有任何提示。你以为改好了，下次进来发现还是老值。

现在会弹一句：

> **还有未保存的修改** —— 离开这一页会丢掉刚才的改动。
> 　［继续编辑］　［放弃修改］

默认那一侧是**继续编辑**（不丢东西的那一侧）。保存成功之后再返回就不会再问了。

> **没改过东西时不会弹框。** 这一点专门做了测试：如果只要"输入框里的字和默认值不一样"就弹，
> 那每次进设置页再返回都会弹一次，你很快就会开始无脑点"放弃修改"——那还不如不提示。

### 首次引导现在能带你做第一件事

第一次启动时，确认完关键默认值之后，引导**不再就此结束**，而是给你三个真实的入口：

```
[创建第一个任务]   ← 已经用过的话，这里写「再创建一个任务」
[导入课表]
[了解主要界面]
```

**建任务走的是和平时完全一样的那条路**（同一个任务表、同一套默认值和校验，
建好之后可以编辑、删除、完成、拆分、参与重排，统计和日历里照常显示）。
引导**不会**给你的任务加任何特殊标记，也**不会**偷偷贴标签。

### 「退出」「跳过」「完成」是三件事

这三件事以前分不开——退出也可能被当成"做完了"，于是你下次再也看不到引导。
现在它们各自有明确的结果：

| 你的操作 | 结果 |
| --- | --- |
| **中途退出**（关窗口／返回主界面／程序崩了） | **不算完成**。下次启动会问：<br>`上次的新手引导还没有完成`　［继续引导］［重新开始］［暂时跳过］ |
| **暂时跳过** | 只跳过**这一次**。下次启动还会问——它没有放弃引导 |
| **跳过引导** | 以后不再自动弹出。之后从**设置**里再打开会进引导首页，不会直接把你扔进任务编辑器 |
| **完成** | 不再自动弹出 |

**「重新开始」只重置引导进度。** 已经建好的任务、导入的课表、已确认的计划
**一个都不会删**。

### 引导里生成的计划，看的是"今天"

规划窗口是**你本机的今天零点**起、往后 7 个自然日。比如 10 月 7 日进引导，
窗口是 `2026-10-07 ～ 2026-10-13`。

**这不代表硬把任务塞进今天**：如果今天已经很晚、没有空档、或者不满足最早开始时间，
第一个任务会被排到明天或之后。

**重新打开引导时按当天的日期重算**，不会沿用上次进来时存下的旧日期。
