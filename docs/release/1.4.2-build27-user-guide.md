# 智能日程 1.4.2+27（开发构建／待验收）

本版修两个你实测遇到的问题，并加一个完成标记。没有新增功能模块，也没有改动数据结构。

## 安装或升级

1. 如果“智能日程”正在运行，请先退出程序；必要时在任务栏托盘图标菜单中选择退出。
2. 双击 `PersonalPlanner-1.4.2-build27-windows-x64-20261006.msix`。
3. 选择“安装”或“更新”。本版 MSIX 版本为 `1.4.2.5`，可以**原位覆盖**本机已有的 `1.4.2.4`
   及更早的 `1.4.2.x` / `1.4.1.0`（不需要先卸载，现有任务、领域颜色、课表和设置都会保留）。
4. 安装完成后，从开始菜单启动“智能日程”。

如果 Windows 提示证书不受信任，请先安装同目录的 `PersonalPlanner-signing-cert.cer`（安装证书 →
当前用户 → 放入“受信任人”）。证书主题应为 `CN=Shuo Zhuang, O=Personal User, C=CN`，指纹
`9E157ECE535D16A224593CA39C084705A4FD3C13`。

> **版本只能往上走**：Windows 不接受比已安装版本更低的安装包。一旦装过 `1.4.2.5`，就回不到
> `1.4.2.4` 及更早的号。

## 本次变化

### 1. 勾选完成后，卡片不再变成「已安排任务」

此前勾选完成后，那条已确认的计划块会变成标题「已安排任务」、分类「无领域任务」，**颜色也跟着变**
——看起来像"任务被换成了另一个分类"。根因是日程数据源只从"未结束任务"里查标题与领域，任务是
完成了但计划块还在，于是查不到、走了兜底分支。现在会补查一次，**保留真实标题与领域颜色**。

### 2. 新增「已完成」标记

- **任务**：勾选完成后，它的计划块在今日、七日日历、单日详情里都带一个对勾标记；
- **固定日程**：结束时间过去后，同样带这个标记（固定日程没有"勾选"这个动作，它的完成就是时间过去）；
- **保护时间不标记**：它不是待办，"午餐时间已经过去"不需要被标记。

标记也会进无障碍语义（读屏会读出"已完成"）。

### 3. 「领域与项目」页的卡片不再贴在一起

领域、特殊日程颜色、项目这三处列表的卡片此前**圆角边框直接贴在一起**（实测上一张的下边框在
`y=522`、下一张的上边框在 `y=523`，只差 1px），彩色颜色圆点看起来挤成一堆。现在相邻卡片之间
留出 8px。

## 便携版

保留本目录内全部运行文件，然后双击 `personal_planner.exe`。不要只把 EXE 单独复制出去；它依赖同目录
的 DLL 和 `data` 文件夹。
