# 智能日程使用教程

> 适用版本：Windows 深色专注版 1.0.8  
> 更新日期：2026-10-06  
> 数据策略：本地优先，无需注册账号，任务与日程不会上传到网络。

![今日页界面](../design-qa/today-implementation-final.png)

## 1. 软件能帮你做什么

智能日程会综合以下信息，滚动规划未来 7 天，同时检查更远的截止日期：

- 待办任务及预计时长；
- 课程、会议、聚餐等固定日程；
- 睡眠、午餐、晚餐和固定休息等保护时间；
- 高、中、低精力区间；
- 每日可移动任务上限；
- 学习、学生工作、竞赛、科研、生活娱乐等领域；
- 任务优先级、截止日期、期望时段和已完成进度。

系统不会为了让日历“看起来排满”而忽略冲突。如果时间确实不够，调整预览会显示冲突、逾期风险或时间缺口。

## 2. 启动程序

### 2.1 使用免安装版

1. 解压完整 ZIP 文件。
2. 打开解压后的文件夹。
3. 双击 `personal_planner.exe`。

请不要只复制 EXE。程序旁边的 `data` 文件夹、DLL 文件和 `native_assets.json` 都是运行所需文件，也不要直接在压缩包内部运行程序。

### 2.2 Windows 安全提示

如果 Windows 第一次启动时弹出安全提示，请先确认文件来自可信来源，再选择继续运行。若双击后没有界面，可检查：

1. 是否已完整解压；
2. EXE 是否仍和 `data`、DLL 文件放在同一目录；
3. Windows Defender 或其他安全软件是否拦截；
4. 是否已有一个智能日程窗口正在后台运行。

> 免安装 EXE 为避免 Windows 原生通知组件导致启动崩溃，会安全关闭系统通知。需要完整 Windows 通知能力时，应使用 MSIX 安装版。

## 3. 第一次启动

第一次打开程序会看到“先照顾好生活，再安排任务”。你有三种选择：

- **一键采用默认设置**：适合先快速体验；
- **修改设置**：立即调整作息、精力与任务容量；
- **稍后设置**：先进入软件，以后从“设置”修改。

默认值如下：

| 项目 | 默认值 |
| --- | --- |
| 高精力 | 09:00–12:00 |
| 中精力 | 14:00–17:00 |
| 低精力 | 19:00–22:00 |
| 睡眠保护 | 23:30–07:30，最低 7 小时 |
| 午餐保护 | 12:00–13:00 |
| 晚餐保护 | 18:00–19:00 |
| 专注节奏 | 专注 50 分钟，休息 10 分钟 |
| 任务片段 | 30–90 分钟 |
| 每日可移动任务上限 | 360 分钟 |
| 每周生活娱乐配额 | 360 分钟 |
| 信任自动调整 | 关闭，先预览再确认 |
| 偏好学习 | 开启建议，关闭自动采用 |
| 应用锁 | 关闭 |

这些只是可修改的起点，不是健康建议。高、中、低精力区间既可以手动调整，也可以在积累足够行为记录后，由“学习偏好”提出建议。

## 4. 主界面与导航

左侧导航共有六个一级页面：

| 页面 | 用途 |
| --- | --- |
| 今日 | 查看当天时间线、保护时间和任务容量 |
| 任务 | 详细新建、搜索、排序和批量管理待办 |
| 领域 | 管理学习、科研、竞赛、生活等领域与项目 |
| 日历 | 查看未来 7 天、管理固定日程和移动计划块 |
| 统计 | 查看计划时间、实际投入、完成情况和复盘反馈 |
| 设置 | 管理规则、外观、偏好、通知、备份、导出和应用锁 |

右上角的 **生成计划** 用于根据当前任务、固定日程和规则重新计算日程；**特殊日** 用于处理晚归、加班或游玩到很晚等情况。

一级页面不会显示返回键。进入任务详情、专注、日历编辑、设置子页、特殊日或调整预览后，可使用左上角的统一返回键回到对应父页面。

### 4.1 切换玻璃材质

进入 **设置 → 外观与材质**，可以随时切换以下四档效果。选择后立即生效并保存在本机，下次启动会自动恢复。

| 模式 | 特点 | 建议 |
| --- | --- | --- |
| 无玻璃效果 | 不透明深色界面，边界最清晰 | 适合低性能设备或希望界面最稳定时 |
| 克制版 | 柔和磨砂、细亮边和轻微环境光 | 默认模式，适合长期使用 |
| 激进版 | 更明显的透明层次、模糊和悬浮深度 | 适合希望玻璃感更强时 |
| 极致版 | 高透明液态层次、双重折射亮边和随鼠标流动的高光 | 光感最强，性能开销最高 |

极致版参考液态玻璃的视觉语言，由 Flutter 在 Windows 中实现，并非调用 Apple 官方材质接口。为保证阅读，输入框和长文本区域仍会保持较高不透明度。若 Windows 开启了“减少动画”或类似辅助功能，动态高光会自动变为静态；如果拖动窗口或滚动时不够流畅，请切回克制版或无玻璃效果。

## 5. 推荐的第一次使用流程

为了让第一次排程更合理，建议按以下顺序操作：

1. 在“设置 → 规划规则与默认值”确认作息和精力区间；
2. 在“领域”建立学习、科研、竞赛、学生工作、生活等分类；
3. 在“日历”录入课程、会议、约会等固定时间安排；
4. 在“任务”录入需要完成的事项；
5. 为重要任务补充截止日期、优先级、项目和期望时段；
6. 点击右上角“生成计划”；
7. 查看调整预览，确认无误后点击“确认应用”。

## 6. 建立领域和项目

领域用于表达长期方向，项目用于表达其中更具体的一组事项。例如：

```text
学习
├─ 高等数学
└─ 英语六级

科研
└─ 论文实验

竞赛
└─ 数学建模

生活（标记为生活领域）
├─ 摄影
├─ 电影
└─ 游戏
```

进入 **领域** 页面后，可以：

- 新建或重命名领域；
- 将某个领域标记为“生活”；
- 在领域下新建项目；
- 归档或恢复项目。

把娱乐项目放在已标记的生活领域下，系统才能把相应任务计入每周生活娱乐配额，而不是把休息时间当作“浪费”。

## 7. 添加和管理任务

### 7.1 详细新建

进入 **任务** 页面：

1. 点击右上角 **新建任务**；
2. 程序会先显示你的默认专注时长、最短片段和最长片段；
3. 填写标题，并按本任务修改预计时长、优先级、精力要求、截止时间和所属项目；
4. 选择“可拆分”或“必须连续”；可拆分任务还可以修改每段的最短和最长时长；
5. 按需填写期望时段与备注；
6. 检查无误后点击 **保存任务**。

新建过程中不会先生成一条不完整的收集箱记录；只有点击保存后，完整任务才会进入待安排列表。默认值只是起点，所有显示出来的字段都可以在保存前修改。标题不能为空，预计时长必须大于 0。

“可拆分”适合论文、复习、编程等可以分多次完成的任务；“必须连续”适合考试、电影、实验流程等需要一次完成的事项。连续任务会按完整剩余时长寻找一段连续空闲时间。

### 7.2 查看任务详情

点击任务左侧的箭头进入详情页。这里可以：

- 调整优先级；
- 设置、延后或清除截止时间；
- 归属已有项目，或直接新建项目并归属；
- 新建和选择标签；
- 设置期望时段；
- 修正剩余时长；
- 按专注记录重新计算剩余时长；
- 转为固定日程；
- 取消事项；
- 开始专注。

“期望时段”是软偏好。例如填写 `19:00–21:00`，系统会尽量把任务排在这个时间，但不会因此突破睡眠、固定日程等硬约束。跨午夜时段也可以使用，例如 `23:00–01:00`。

### 7.3 完成、搜索和批量操作

- 普通模式下，勾选任务表示完成；取消勾选可恢复为未完成。
- 搜索框可按标题筛选任务。
- 排序支持默认顺序、截止时间、优先级和预计时长。
- 点击“多选”后，点击任务行会改为选择任务，不会直接完成。
- 多选后可统一设置优先级、截止日期，或取消所选事项。

### 7.4 如何记录聚餐、摄影和游戏

判断标准不是“学习还是娱乐”，而是时间是否固定：

| 情况 | 推荐记录方式 |
| --- | --- |
| 周六 18:30 已约好的聚餐 | 固定日程 |
| 周三晚想看一部电影，但时间可调整 | 任务，预计 120 分钟，归属生活项目 |
| 每周四固定社团活动 | 每周重复的固定日程 |
| 本周想安排一次摄影外拍，时间可协商 | 任务，设置截止日期和期望时段 |
| 已买票的演出或电影 | 固定日程 |
| 想玩 90 分钟游戏放松 | 生活领域下的任务 |

## 8. 添加固定日程

进入 **日历 → 新建固定日程**：

1. 填写标题；
2. 选择开始与结束日期、时间；
3. 如果是课程、例会或固定训练，开启“每周重复”；
4. 点击“保存日程”。

固定日程不会被自动排程移动。对于重复日程，可在日视图中选择“改这一次”或“改整个系列”；删除时可选择“只删这一次”或“删除整条”。

在周视图中，可以把可移动任务块拖到另一日。确认移动时：

- 勾选“锁定”：以后自动重排也不会再移动这一块；
- 不勾选：本次移动仍然生效，但后续重新排程可以再次调整。

每个日程气泡会直接显示开始与结束时间。点击某一天的日期标题，或点击该天任意日程气泡，可以打开当天的具体日程。

### 8.1 从课表图片批量导入课程

打开 **日历 → 导入课表**。向导分为五步，中途返回上一步不会丢掉已编辑的内容。

1. **上传**：选择 PNG 或 JPG 课表截图。手机截图包含状态栏或底部导航时，可以裁剪识别区域；图片方向不对则先旋转，再点“重新识别”。
2. **校对**：逐门确认课程名、教师、教室、星期、起止节次、教学周和单双周。课程默认归入“学业”领域；如果要归入某个项目，先选领域，后面的项目列表只显示该领域下的项目。
3. **学期**：填当前周数或第一周周一，另一项会自动换算。图片中识别到的总教学周数只是草稿，可以直接改。
4. **节次**：把“第 1 节”这类标记对应到真实时间。程序先显示默认时刻，你可以选现有模板，也可逐节修改。
5. **预览**：查看课程数、重复系列数、具体课次、冲突和重复项。没有点“确认导入”之前，这些内容都不会写入日历。

冲突课次有三种处理方式：保留并标记待处理、仅排除这一次、跳过整门课。完全相同的课程默认跳过；只是教师或教室不同时，预览会把它标成可能的信息变更，由你决定保留现有课程还是新建。

导入的课程会成为锁定的固定日程，自动排程会避开它们。完成后底部会出现“撤销本次导入”；如果其中某门课已被手动修改，撤销时会先提示，不会静默删除你的修改。

识别在 Windows 本机完成，图片不会上传，也不会进入数据库、备份或导出文件。数据库只记录图片哈希和文件名，不保存原路径。如果系统没有简体中文 OCR，可在 Windows **设置 → 时间和语言 → 语言和区域** 补充简体中文语言组件，或直接选“手动录入课程”继续。

## 9. 生成并确认计划

完成任务和固定日程录入后，点击右上角 **生成计划**。

程序会考虑：

- 截止日期与优先级；
- 预计时长和剩余时长；
- 固定日程、睡眠与用餐保护；
- 高、中、低精力区间；
- 专注片段长度和片段间休息；
- 每日可移动任务上限；
- 每周生活娱乐配额；
- 任务的期望时段；
- 已锁定的计划块。

生成后进入 **调整预览**，其中会按类别显示：

- 新增；
- 移动；
- 拆分；
- 移除；
- 冲突。

点击具体条目可展开查看原因。确认无误后点击 **确认应用**。

如果页面提示“提案已过期”，说明任务、规则或日程在生成后发生了变化。点击 **重新生成计划**，不要继续使用旧提案。

任务或日程变化后，底部可能出现“计划已按最近的改动重算，等待你确认”。点击右侧 **查看调整** 可进入预览；如果暂时不想处理，可点击提示左侧的关闭按钮。关闭只隐藏本次提示，不会删除仍待确认的调整方案。

如果想撤回刚刚应用的方案，可以点击 **撤销上一次计划**。

### 9.1 “先预览”和“信任自动调整”的区别

- **关闭信任自动调整**：变化发生后先生成提案，由你查看并确认；适合刚开始使用。
- **开启信任自动调整**：符合规则的调整可以自动应用，但系统仍会校验并保存差异和原因历史。

建议先使用一到两周的“先预览”模式，确认规则符合自己的习惯后，再决定是否开启自动调整。

## 10. 使用今日页

今日页由两部分组成：

- **今日时间线**：按时间顺序显示固定日程、保护时间、可移动任务和生活事项；
- **计划摘要**：展示今日容量和安排概况。

颜色只是辅助识别，界面还会显示文字类型：固定、保护、可移动任务或生活事项。今日页只显示当前本地日期内的安排，不会混入后面几天；跨午夜事项只显示落在今天的部分。页面使用用户本地时区，不需要手动换算 UTC。

## 11. 使用专注计时

进入 **任务详情 → 开始专注**：

1. 点击“开始”；
2. 需要中断时点击“暂停”；
3. 选择暂停原因，或点击“跳过”只记录一次未分类中断；
4. 点击“继续”恢复计时；
5. 结束后点击“完成”。

如果继续专注时已经超过原计划时段，程序仍允许继续，并会提示剩余任务需要重新排程。

如果程序在计时过程中异常退出，下次进入专注页时会要求确认真实结束时间和实际时长。只有确认后的记录才会进入统计；也可以选择“不计入本次”。

忘记开计时器时，可以使用“补录已完成的专注”。

## 12. 临时变化与重新排程

### 12.1 突然增加会议、聚餐或课程

1. 在日历中新增对应固定日程；
2. 点击“生成计划”；
3. 查看哪些任务被移动、拆分或产生冲突；
4. 确认应用。

### 12.2 某项任务比预计花得更久

- 如果仍在专注，继续计时；超出原计划时段后程序会触发重排提示。
- 如果已经结束，在任务详情中“修正剩余时长”，再重新生成计划。

### 12.3 临时晚归、加班或出去玩到很晚

点击右上角 **特殊日**：

1. 填写实际结束时间；
2. 选择处理方式：
   - 重新安排可移动任务；
   - 取消次日可移动任务；
   - 安排补觉；
   - 单次接受较短睡眠；
3. 点击“生成恢复方案”；
4. 点击“查看调整预览”；
5. 检查固定日程、最低睡眠冲突和被移动的任务后确认。

特殊日只影响本次恢复方案，不会悄悄改掉长期作息。

### 12.4 只想临时提高一天的任务上限

进入 **设置 → 临时放宽每日上限**：

1. 填写当天允许的可移动任务分钟数；
2. 点击“放宽这一天”；
3. 需要恢复常规限制时，点击“清除这一天的放宽”。

这不是修改长期规则，只作用于指定的一天。

## 13. 查看统计与复盘

进入 **统计** 页面，可以选择：

- 今天；
- 本周；
- 本月；
- 自定义范围。

统计页会分别展示计划时间和实际投入，不会把二者混为一谈。可查看的内容包括：

- 完成率与按期完成情况；
- 各领域、项目和标签的时间分布；
- 计划与实际投入差异；
- 趋势；
- 高、中、低精力区间的表现；
- 常见中断原因；
- 重新排程原因；
- 休息保护与生活娱乐投入；
- 基于实际证据生成的正向反馈和改进提示。

使用“按标签筛选”时，可以选择多个标签；多选表示任务必须同时拥有全部所选标签。若统计为空，先确认：

1. 当前时间范围内是否有已确认的专注记录；
2. 任务是否已完成或有实际投入；
3. 标签筛选是否过窄；
4. 是否选择了正确的日期范围。

## 14. 偏好学习

进入 **设置 → 学习偏好**。程序会根据非特殊日的已确认记录提出软偏好建议，例如更适合某类任务的时段。

每条建议都可以：

- 查看依据；
- 修改建议值；
- 确认采用；
- 拒绝；
- 停用；
- 清除学习结果；
- 撤销上次自动更新。

学习偏好只影响软排序，不会修改最低睡眠、用餐保护、固定日程或每日上限。证据不足时，页面会显示“目前还没有达到证据门槛的建议”，这是正常状态。

## 15. 规划规则与通知

进入 **设置 → 规划规则与默认值**，可以修改：

- 工作日和周末睡眠；
- 最低睡眠时长；
- 午餐、晚餐和固定休息；
- 工作日和周末的多个精力区间；
- 默认专注时长；
- 片段间休息；
- 最短、最长任务片段；
- 工作日和周末的每日可移动任务上限；
- 每周生活娱乐配额；
- 信任自动调整。

通知设置也在这个页面，包括：

- 任务开始提醒；
- 固定日程提醒；
- 截止临近提醒；
- 冲突待处理提醒；
- 各类提醒的提前分钟数；
- 免打扰开始和结束时间。

普通通知落在免打扰时间内时会延后，冲突待处理提醒仍会保留。修改后务必点击页面底部的 **保存设置**。

## 16. 数据导出、备份与恢复

### 16.1 导出数据

进入 **设置 → 数据导出**：

- “导出完整 JSON”适合迁移、开发分析或保留结构化数据；
- “导出 CSV”适合使用 Excel 等表格软件查看。

导出文件会明确区分计划时间和实际投入。取消目录选择不会创建文件。

### 16.2 创建备份

进入 **设置 → 数据备份与恢复 → 创建备份**，选择保存位置。建议：

- 每周至少备份一次；
- 大批量修改或升级程序前先备份；
- 将备份复制到其他磁盘，避免电脑故障时一起丢失。

### 16.3 恢复备份

1. 点击“验证并恢复”；
2. 选择备份文件；
3. 程序会验证版本、文件长度、SHA-256 哈希和数据库完整性；
4. 确认恢复；
5. 关闭并重新打开程序，让恢复结果完整生效。

恢复会替换当前本地数据库，操作前建议先为当前数据创建一份新备份。

### 16.4 永久清除

永久清除会删除本机数据库、通知和应用锁凭据，但不会删除你自行导出的外部文件。需要输入确认短语：

```text
永久删除我的全部本地数据
```

清除安排会在下次启动时执行。此操作不可撤销，执行前应先备份。

## 17. 应用锁

进入 **设置 → 应用锁**：

- 开启时需要输入两次相同且非空的密码；
- 关闭时需要验证当前密码；
- 多次输错会逐步延长等待时间。

应用锁只阻止他人通过正常界面打开程序，不会加密本地 SQLite 数据库，也不能替代 Windows 账户密码、BitLocker 或其他磁盘加密。当前版本没有面向用户的密码找回流程，开启前请妥善保存密码。

## 18. 推荐的日常使用习惯

### 每天早上或前一晚

1. 用“新建任务”完整填写当天新增的待办；
2. 补充当天新增的课程、会议或约会；
3. 点击“生成计划”；
4. 查看调整预览并确认。

### 执行过程中

1. 从任务详情开始专注；
2. 如实记录暂停和实际投入；
3. 临时事件发生时先更新日历，再重新排程；
4. 不要为了“完成计划”而删除睡眠或用餐保护。

### 每周复盘

1. 在统计页选择“本周”；
2. 查看时间主要花在了哪些领域；
3. 比较计划与实际投入；
4. 查看常见中断和重排原因；
5. 检查生活娱乐时间是否被长期挤压；
6. 到“学习偏好”审阅新建议；
7. 创建一份数据备份。

## 19. 常见问题

### 为什么计划没有排下所有任务？

可能是固定日程、睡眠保护、每日上限和截止日期共同造成容量不足。请查看调整预览中的冲突信息。可以延后任务、修正剩余时长、调整优先级、临时放宽某一天，或减少不必要的固定占用；不建议直接牺牲最低睡眠。

### 为什么修改任务后旧计划不能确认？

旧提案已经过期。点击“重新生成计划”，让系统基于最新数据重新计算。

### 为什么统计页没有数据？

统计依赖完成记录和已确认的专注记录。只建立任务但没有执行记录时，实际投入自然为空。

### 为什么便携版收不到通知？

免安装 EXE 当前会关闭 Windows 原生通知，以保证程序稳定启动。使用带 Windows 包身份的 MSIX 安装版才能获得完整通知能力。

### 数据存在哪里？

核心数据保存在本机 SQLite 数据库中，不会上传。程序升级或更换电脑前，应使用“创建备份”或“导出完整 JSON”保存副本。

### 社交和娱乐会不会被系统当成不重要？

不会。将对应项目放入已标记的生活领域，并设置生活娱乐配额后，系统会把这部分时间作为需要保护和衡量的生活投入。已有明确时间的活动应录入固定日程，时间可调整的活动应录入任务。

---

建议第一次先使用默认设置和“先预览再确认”模式。连续使用一到两周后，再根据统计和学习建议逐步调整精力区间、每日容量与自动调整开关。
