# Windows 手工验收清单

Task 20 的交付物之一。本清单用于在 Windows 桌面上逐项确认自动化测试覆盖不到的行为，
并作为需求规格第 18 节验收清单的证据来源。

**使用方式**：每项填写「通过 / 不通过 / 不适用」并在证据栏留下截图、日志路径或构建号。
任何「不通过」项不得标记首版完成。不要在没有实际执行的情况下预填结果。

**当前状态（2026-10-02）**：Task 20 尚未完成，本清单**尚未执行**，因此需求规格第 18 节
全部保持未勾选。清单中标注「当前不可达」的条目需要先完成对应接线或实现，见技术设计
文档 §13.0 的偏差登记。
